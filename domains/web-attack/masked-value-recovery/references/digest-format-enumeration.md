# 摘要格式枚举战役 — 工程与解释（实战定型）

## 工具链基线
- C 版生成器：targets = 32B 二进制哈希表（百万级 → 3200 万槽表，秒级装载）；8 线程；单次调用 = 前缀/模板 × 位数满空间；命中 append 到 out.tsv（candidate<TAB>hash）。
- 吞吐参考：8 核 ~12M 候选/s → 10^10 空间 ≈ 13–14 min/族；与其它重型任务共存时按 nice 分层（queue 用 nice 12，临时 python nice 10+ 防抢核）。
- 模板模式 `{n}` 分组（如 `'+52 1 {2} {4} {4}'`）；`@BARE@` = 空前缀；一次调用可排队多前缀；多摘要版（sha3-256 / blake2s / sha512-256 / 双 sha256）同候选同表扫。

## 战役配置
- 每族一行日志：`--- run[名] 'prefix' d=digits HH:MM ---` + `cum_hits`；每段独立 out 文件，汇总再聚。
- 队列用 done-marker 串行接力（partN 写完 marker → partN+1 自启），断点即日志；跨夜长跑必备。
- 家族顺序：先跑“用户最可能输入”的胶合格式族，后跑空格/主干前缀/括号/横线补漏族。

## 金丝雀校准（任何结论前第一步）
- 往目标表注入 1 个已知：自控明文 → 系统里触发一次写入 → 拿其摘要，做成小 targets 文件。
- 用同一工具跑“应命中”格式族：找到 = 管线/速度/比对全通，之后 0 命中才有判定力；找不到 = 先修管线，别下结论。
- 单一摘要版与多摘要版各验一次（防某一版静默坏掉）。

## 最小段全空间证伪（最关键战术）
- 挑最小、最同质的 license/分段（实测：49 条 / 4,129 条 / 5 条），其全部标准格式族 × 全空间跑完。
- 全零 → “标准格式普通哈希”判死（数千条 × 全空间 = 秒~分钟级，比大集合快几个量级）。
- 后补多摘要阶梯同样全零 → 判死更硬。

## 先验抽样（别照标签猜国别）
- 分段（license/品牌）≠ 用户国籍：抽样各分段 COUNTRY 分布（数仓/CRM 联表）再定格式族。
- 教训：按标签国（Curaçao 等）的格式族跑完 = 0 且无关；实际混合 MZ/RU/BR/IN/GR/IE/GB —— 换对国格式全空间跑仍然 0 → 反向坐实“非标准格式”。

## 结果解释
- 跨分段、跨格式族、多摘要持续全零 + 校准通过 → **带密钥形态（HMAC / 带密钥加密）**：停枚举；转密钥落点（KMS/vault/k8s secret/服务 env，内网）或真值旁路（网关侧明文日志、导出仓、显示神谕）。
- 同系统两代形态（旧：裸 64hex；新：`v1$$<keyid>$$...`）互为线索：迁移期用户的“同秒双写”行 = 已知对设计的素材。
- 验证确定性：同号同值（摘要确定性）用重复写入/多用户同号验证。

## 工程踩坑
- pkill/pgrep 防自匹配：脚本名不得出现在 kill 命令行的其它位置（含作为其它命令参数）；杀+拉起全放独立脚本，调用只写 `bash restart.sh`。
- 长队列输出别混：每段独立 out，最后统一 `wc -l` 全部 out 查命中。
- 大量 python 抢核会让 nice 化的 cracker 变慢：临时任务加 nice -n 10。

## 跨源联结 / 代际分空间 / 字面量盐（2026-10 补充）
- 数仓导出常见列型：`hash<TAB>uid<TAB>版本列<TAB>品牌<TAB>国家`；版本列 = 摘要代际。**各代际 = 独立密钥空间**：先按代际分组、各自挑最小段跑全空间，「判死」结论按代际分别达成。
- uid 联结扩对：工单/客服库存 uid↔明文，数仓存 hash↔uid → 按 uid 联结，已验证对 64→1000+；同号多用户哈希全同 = 无按用户盐（16/19 实证）。
- 字面量盐快速排除表（实测全灭，供复刻，分钟级）：`main_key_id_v1, v1$$, signup_deduplication_hashes, SIGNUP_DEDUPLICATION_HASHES, dedup, dedup_v1, phone_number_hash, shared-apps, torrero, 品牌名` × {前/后缀, :, |, _, -} × {sha256, HMAC} ≈ 5.7 万组合 / 80 对 = 0。
- 广告导出线（Google/Meta 规范）通常是**无密钥** SHA256：先在已验证对上测「小写+E164+去点(gmail)」与「仅 trim」两种归一化，再谈密钥结论。
- 全空间证伪模板（新代际 uk 段实例，整段 2.4 万条判死）：`+447{9} / 447{9} / 07{9} / +44 7{3} {6} / +44 7{4} {5} / +441{9} / +442{9} / +44{10} / 44{10} / 7{9}` 共 11 模板 × 8 核 ≈ 40 分钟出结论。
