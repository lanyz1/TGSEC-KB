# 显示遮罩神谕 — 实战案例（Django-admin 消息后台）

## 场景
- 后台把号码/邮箱全部显示遮罩：列表、详情、编辑表单 input、constance JSON、报表，一律 `+XXX****NNNN` 形态。
- 但列表搜索框 `?q=` = Django-admin `search_fields` → DB 层 `icontains` 打**未遮罩**存储值。

## 还原实录
- 目标值已知形态：`+XXX****NNNN`（前 4 + 后 4，中段隐藏，长度未知）。
- 探法：`GET /<adminapp>/messaging/message/?q=<候选>` → 读命中行数（0 vs >0）。
- 顺序：中段从左到右逐位枚举 0–9（每步 10 请求），命中即锁定该位。
- 结果：~55 请求还原完整值；终局三件套验证：完整值 → 命中（含目标行）；±1 相邻 → 0；控制串 → 0。
- 另一目标（cascade 规则表）同法 ~35 请求还原。同类可试表：message / dbsmscascaderule / dbmessageretries。
- 关键：无需任何漏洞 —— 权威面板自带搜索预言机；遮罩只在渲染层。

## 推广清单
- 优先测的字段：电话、邮箱、卡号、证件；“看起来不能搜”的字段在 querystring 里往往也能过滤（`?field__icontains=`、`?field__gte=`）。
- Django-admin 有用参数：`?o=` 排序、`?p=` 翻页、字段/日期过滤（`?created_at__year=`）、`q=` 主力。
- 行数比较是最好的读数（页面大字 “N results”）；无需拉全行。
- 长度未知时：逐位推进直到完整命中（前缀变长时命中数收敛到 1）。
- 控制臂：任意不存在值必须 0；排除缓存/模糊命中。

## 噪声与边界
- 每请求 = 一条后台日志；单号几十请求可接受，不做全量扫描。
- 只能还原“库中已有”的值（一次一位）；不能枚举新值空间（那属于摘要/枚举线）。
