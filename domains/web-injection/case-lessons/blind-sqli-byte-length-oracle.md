# 案例课：用响应字节数当布尔盲注的真假判据

> 来源：同行作业机样本 + 本机复现口径（2026-10）· 域：web-injection / sqli
> 原文与凭据不入库；本文只留可复用手法。

## 一句话

当盲注既没有回显、内容匹配又被 WAF 和动态片段干扰时，**响应体长度本身就是一个稳定的布尔信道**：`and 1=1` 与 `and 1=2` 的字节差通常是常数，取中间值做阈值比正则匹配可靠得多。

## 前提 / 指纹

- 注入点可打布尔（`and 1=1` / `and 1=2` 不报错、不跳转）
- 页面由同一模板渲染，主体内容随查询结果变化（列表/详情/统计）
- 有 CDN 或 nginx gzip 时，长度会被压缩打乱 → 先关 `Accept-Encoding`

## 链

```text
基线采样（真/假各 3 次）→ 算字节差 → 定阈值区间
→ 逐字符 substr 布尔 → 命中区间即 1，否则 0
→ 每 N 字符复采基线，防页面模板漂移
```

- 实测口径（照抄报告原文）：真 `and 1=1` → **10,687 B**；假 `and 1=2` → **7,473 B**
- 阈值取中间：`>10,000` 判真，`<8,000` 判假；落在中间带的重采一次
- 取数 payload 骨架：`and ascii(substr((<子查询>),<i>,1))><mid`
- 每字符请求加 ±随机 sleep（0.3–1.2s），避免等长响应被 WAF 聚类成扫描

## 判据与边界

- 命中判据：同一参数同一页面，真假响应字节差 **≥ 1KB 且 3 次重采方差 < 50B**
- 失败边界：
  - 页面含时间戳/随机广告位/CSRF token → 长度每次抖动，先找稳定页（如详情页固定 id）
  - 结果集为空与报错页等长 → 换 `and (select 1)=(select 1)` 型恒真式再测
  - 有 gzip/br → `curl --compressed` 关掉或固定 `Accept-Encoding: identity`
  - 排序/分页参数参与注入时，长度差可能来自排序而非条件，必须同参数对照
- 同族变体：时间盲注（sleep）、带外（DNS/HTTP）、布尔内容匹配（`in`/正则）——按 WAF 规则强弱选，字节数法对内容类 WAF 最不敏感

## 检查清单

- [ ] 确认无 UNION / 无报错回显，才退到盲注
- [ ] 关压缩、固定 UA 与 Cookie，避免 CDN 缓存命中不同副本
- [ ] 真假各 3 次采样并记录字节数，写进案卷
- [ ] 每 50 字符复采基线；发现漂移立刻重定阈值
- [ ] 取数前先 `select @@version` 验证字符集与大小写敏感性
