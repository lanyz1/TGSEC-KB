# 女性换装导演（female-outfit-director）

把一次角色穿搭需求转成彼此联动的 5 件产物：参数锁定结果 → 首帧拼贴图提示词 → 换装视频时间轴 → 精简视频提示词 → 负面提示词/强制约束。

**图片是视频的结构母图**：视频必须继承图片中的人物身份、服装、四周小人物位置、布局与摄影质感。

移植自 github.com/liyue-aigc/female-outfit-director（MIT, v1.3）。第 5 节「完整输出协议」为本地补齐（上游 SKILL.md 只写到第 1 节就断了，详见 Pitfalls）。

## 触发范围
- 同一角色的多套穿搭拼贴图 / 真人化角色 + 多套造型
- 中央大人物 + 四周悬浮人物贴纸；点击某个小人物后变装
- 把角色穿搭图变成卡点换装视频；汉服/古风/国风/现代时尚/虚拟角色的卡点换装
- 先推荐参数组合再生成提示词；上传参考图后沿用人物、服装和布局；更换/推荐换装机制

不走本卡：普通单人写真、单套服装展示、纯剧情短片（除非用户明确要多套换装联动）。

## 工作模式
- **A 直接生成**：已有参考图/人物设定/足够服装信息 → 锁定已知参数，只补全低风险缺项，直接出图提示词 + 视频脚本，不重复追问已给信息。
- **B 参数推荐**：用户说"推荐几组参数/先给方案" → 读 `references/parameter-presets.md`，输出 4–8 组差异明显的组合，**暂不出**完整提示词；选定后进 A。
- **C 参考图提取**：读图提取人物外貌、族裔外观、年龄感、发型发色、头饰耳饰；区分中央主造型与四周造型；提取位置、比例、朝向、背景、光线、描边；看不清的非核心细节系统补全；**不用文字模板覆盖图中已明确的设定**。
- **D 机制改造**：已有脚本只换变装方式 → 保留人物/服装/镜头/时长/布局，只替换换装触发与动作；读 `references/transition-library.md`；要多个方案就给 3–6 个。

## 参数锁定规则（用户给的参数一律锁定，不得擅自替换/弱化/删除）
- **角色锚点**：名称/身份、明确成年年龄或视觉年龄、国籍/族裔外观、脸型、五官与神情、肤色、妆容、眼睛、发型/发色、头饰/耳饰、整体气质
- **国籍与族裔外观铁律**：有参考图 → 严格遵循图中可见族裔外观，不用默认值覆盖；用户指定 → 严格用用户设定；**无参考图且未指定 → 默认原创中国成年女性**（视觉年龄 22–28，自然真实东亚面部特征），且必须在参数锁定结果、图片提示词、视频提示词里**显式写出"中国成年女性"**，不能只靠中文语境暗示。除非用户明确要求，不得自动生成欧美面孔；不得用服饰/妆容/文化符号替代族裔外观，不做刻板夸张化面部特征。
- **造型**：中央初始主造型 + 造型 1–4
- **图片**：画幅、拼贴布局、背景、光线、主色系、小人物描边
- **视频**：时长/比例、机位与运镜、换装机制、动作基调、卡点时间、声音、结尾动作

## 缺失参数处理
不要求用户一次填完。以下未明确时自动补全并在结果中标记 `系统补全`：
中国成年女性（22–28，自然东亚特征）｜图片 9:16｜视频 9:16｜时长 8 秒｜背景浅灰白无缝影棚｜柔和漫射棚拍光｜小人物白色手绘贴纸虚线描边｜视频固定机位｜无文字/品牌/Logo/水印｜基础点击+飞入+卡点音效。

**只有高影响信息完全缺失且无法合理补全时**才问一个简短问题（无参考图也无任何角色设定；要多套服装但既没给服装也没让系统推荐；镜头与换装方式互相冲突）。不要为补齐参数表逐项追问。

## 默认五人拼贴版式
中央偏右大主体（约占画面宽度 60%–65%）｜左上小人物｜右上小人物（默认腰部以上紧凑构图）｜左侧中部小人物｜左下小人物｜右下留白。

硬规则：默认**正好 5 人**；5 人必须**同一角色**；中央最大、四个小人物明显更小；小人物是**沿真实身体轮廓裁切的完整人物抠像**（各自独立白色虚线描边）；中央人物不加虚线；**禁止第六个人物**；**禁止用矩形缩略图替代人物抠像**。用户明确要 3–6 套造型时可改布局，但必须先在参数结果里说明新的布局逻辑。

## 首帧图片生成流程（按此顺序写完整版提示词）
1. 画幅 + 超写实商业摄影任务
2. 统一人物身份与外貌锚点
3. 人物数量与拼贴布局
4. 中央人物构图、姿态、主造型
5. 四个小人物位置、构图、姿态、各自造型
6. 白色虚线贴纸效果
7. 背景、光线、镜头、皮肤、发丝、服装面料
8. 主色系与画面气质
9. 硬性限制
10. 负面提示词

### 为视频兼容而优化（写图提示词时必须内建）
- 小人物不用极端扭曲姿势；头/肩/腰/手臂结构清晰
- 小人物与中央人物**身体拓扑尽量兼容**，便于重合换装
- 袖摆/裙摆/披帛尽量完整，不大幅裁切
- 五个版本的脸、发型、发色、头饰、耳饰统一
- 中央初始姿态要给后续动作留空间；背景保持简洁

## 换装机制选择
用户指定机制 → 严格使用。未指定时按场景分流：
- 拼贴贴纸 + 互动选择 → 默认 **M1 完整人物飞入重合**
- 汉服大袖/披帛 → **M2 长袖遮镜**，其次 M5
- 古风贵女 → **M5 团扇/折扇遮挡**
- 强拼贴设计 → **M8 贴纸翻页/人物剪影翻转**
- 强节奏现代穿搭 → **M10 步伐/跺脚/手势卡点**
- 分身概念/衣橱人格 → M9 分身归位融合｜东方幻想/神女 → 披帛、花瓣、云纹、水墨｜高级清冷时尚 → 旋身、镜面

12 种机制详情、组合限制、偏好优先级见 `references/transition-library.md`。

### 默认机制：M1 完整人物飞入重合（消耗式贴图）
1. 指针点击目标小人物
2. 复制出一个相同的完整人物抠像作为**飞入副本**
3. 原位置目标小人物**立即移除、留空**，不再保留
4. 飞入副本沿斜线飞向中央并迅速放大
5. 白色虚线始终贴合飞入副本的完整人物轮廓
6. 副本与中央人物的头/肩/腰/动作姿态重合 → 触发换装
7. 重合瞬间中央人物切换对应服装，飞入副本与虚线**同时消失**
8. 换装后中央人物继续原动作

必须写明：飞入的是**完整人物副本**不是单独衣服、不是矩形卡片；原位置不保留/不弹回/不再出现；重合后中央只留一个人物、无重影。

## 视频时间轴生成流程
默认 8 秒 = 初始造型 + 4 次换装。默认换装完成点：**1.25s / 2.95s / 4.40s / 6.55s**。
- 总时长变化且用户未给卡点 → 按上述时间点相对 8 秒**等比例缩放**；最后一段必须保留最终造型展示时间
- 用户给了卡点 → **严格使用**，不擅自平均化

每段时间轴必须包含：时间范围、当前造型、人物动作、眼神/表情、换装触发、换装运动方向、换装完成时刻、换装后动作如何延续、发丝/袖摆/裙摆/流苏物理、必要音效。

## 动作连续性
换装前后维持：重心连续、旋转方向连续、手臂轨迹连续、头部朝向连续、眼神变化有因果、**不因换衣重置姿势**。用飞入重合时：必须在头/肩/腰/姿势相合后才完成服装替换。

## 衣料物理
汉服/长裙/长袖/披帛/流苏必须：有自然重力；转身有轻微惯性延迟；停止后逐渐回落；换装瞬间不中断物理连续性；不僵硬漂浮、不穿模、不粘连身体。

## 镜头规则
默认**固定高机位**（拼贴换装最优）：摄影机在人物前上方、向下 30–35°、近距高机位俯拍、人物自然抬眼、头和上半身更靠近镜头、裙摆向画面下方展开；**全程固定，不推拉/不摇镜/不旋转/不变焦**。
用户明确要求时可用：正面固定、轻微低机位、缓慢推近、轻微横移、半环绕。短时长内**不要同时叠加复杂运镜与复杂换装机制**。

## 声音规则
默认**无背景音乐**（用户要求时按要求编排）。按机制加入：鼠标点击声、飞入/滑动短促移动声、换装完成卡点声、轻微衣料摩擦声；古风可加极轻丝带/扇面/花瓣掠过声。声音只服务换装节点。

## 强制一致性约束（完整输出中必须明确写出）
同一张脸｜同一成年年龄感｜同一国籍/族裔外观｜同一肤色｜同一发型/发色｜同一头饰/耳饰｜同一身材比例｜只改变穿搭不重做人物｜换装前后动作连续｜已使用的小人物贴图原位置不保留｜不出现第六人物｜不出现矩形缩略图｜不出现双重中央人物/残影｜不服装叠穿｜不错误肢体/多余手指/身体融合｜不头部裁切｜不背景突变｜不无故镜头移动。

### 2）首帧图片提示词（可直接粘贴到生图模型）
按「首帧图片生成流程」10 步顺序写成**一段完整提示词**（中文对 seedream/qwen 友好），写法要点：
- 开头固定句式：`9:16 竖屏，超写实商业摄影拼贴图，【同一人物锚点描述】。画面共 5 个同一人物：中央偏右为大型主体。`
- 每个小人物逐一定位写死：左上/右上/左中/左下，分别写构图（全身 / 腰以上）、姿态、朝向右下中央、各自造型款式+颜色+面料+层次
- 描边句：`四个小人物均为沿真实身体轮廓裁切的完整人物抠像，各自带白色手绘贴纸虚线描边，无边框、无矩形卡片；中央人物不加虚线`
- 收尾句：背景/光线/镜头参数 + 主色系 + 硬性限制（同一张脸、不得新增人物、不得矩形缩略图、不得文字水印）
- **留白句（实测必需）**：`右下区域为纯背景留白，不得出现任何白色矩形、空白方框、占位色块。` —— 缺这句时 seedream-4-5 会在留白位画一个白色矩形块，视觉上等同“矩形缩略图”，破坏拼贴语义。

### 3）视频时间轴（逐段）
每段固定 10 字段，用列表或表格输出：
```text
[0.00–1.25s] 当前造型：初始主造型
  人物动作：/ 眼神表情：
  换装触发：/ 飞入方向：
  换装完成：1.25s
  换装后延续：
  布料物理：发丝/袖摆/裙摆/流苏
  音效：
```
共 **5 段**（初始造型 [0.00–1.25] + 4 次换装 [1.25–2.95] [2.95–4.40] [4.40–6.55] + 最终展示段 [6.55–8.00]），末段专门留给最终造型展示。

### 4）精简视频提示词
一段话（可直接贴入视频模型），包含：画幅+时长、固定机位描述、人物锚点与不变项、四张待消耗贴图位置、M1 四步因果（点击→复制飞入→原位留空→重合换装后副本与虚线消失）、动作连续性与布料物理、无背景音乐与音效节点。

### 5）负面提示词 / 强制约束
负面提示词（描述式，供模型用）：变脸/换人、年龄漂移、族裔外观改变、发型发色变化、矩形缩略图、多于 5 人、贴图残留或弹回、中央双重人物残影、服装叠穿、错误肢体与多余手指、头部裁切、背景突变、镜头无故移动、文字/品牌/Logo/水印、僵硬漂浮布料、穿模。
并附一段中文强制约束声明（逐条列一致性约束，便于人工核对）。

## 与本机出图链路衔接（本卡只出提示词，出图走另一张卡）
本机已有 APIMart 网关链路（见 skill `ai-image-gen-integration`，脚本 `scripts/apimart_gen.py`）：
- 首帧拼贴需 9:16 竖屏 → 提交时 `size` 传比例字符串 `"9:16"`（不是像素）
- 参考图锁定人物时传 `image_urls: ["url"]`（**字符串数组**，不是对象数组）；多参考融合/人像一致性优先 `seedream-5-0-pro`，快批量用 `seedream-4-5`
- **首帧拼贴模型选型（本机 2026-09 实测，9:16/2K，同提示词）**：`seedream-5-0-pro` 最符合硬规则（四贴纸白描边完整、右下留白干净、服装贴合，但 75s/0.585 cr）→ 首选出图；`qwen-image-3-0` 快且便宜（14s/0.206 cr）但**描边几乎不可见**，贴纸感弱 → 适合内部预览；`seedream-4-5`（32s/0.26 cr）会在留白位画白色矩形块 → 靠留白句+负面词修正后才可用。三图对比见 `references/first-frame-model-notes.md`
- 图像模型全是**异步**：提交得 `task_id` → 统一轮询 `GET /v1/tasks/{id}` → 完成后立即下载（URL 24–72h 过期）
- API 需走本机 v2rayN 代理 `http://127.0.0.1:10808`
- 视频环节本卡不提供付费服务接入，只交付提示词与时间轴脚本

## Pitfalls
- **上游 SKILL.md 的输出协议断尾**：上游文件只写到 `### 1）参数锁定结果` 就结束（无 2–5 节模板、无完整示例输出，README/FIRST_USE 只有调用示例）。本卡第「完整输出协议」的 2–5 节是本机补齐的，不是上游原文。
- **族裔外观必须显式写出**：默认场景漏写"中国成年女性"是最常见错——中文语境不会自动生效，参考图场景则绝对不能用默认值覆盖。
- **小人物被生图模型当矩形卡片**：首帧提示词必须同时写明"沿真实身体轮廓裁切、无边框"并把它放进负面提示词，否则拼贴变成九宫格缩略图，后续 M1 飞入换装直接不可用。
- **M1 的"原位置留空"易被模型理解成"贴图弹回/保留"**：必须显式否定（不保留、不弹回、不再出现），否则出现双重人物。
- **机制不混搭**：一次短视频不要混用超过 2 种主换装机制；8 秒 4 次变装推荐统一一种机制。
- **留白位会出现白色矩形块**：提示词只写“右下留白”时，seedream-4-5 会主动画一个白色矩形/空白方框（实测复现）。必须在描述里同时写“纯背景留白、不得出现任何白色矩形/空白方框/占位色块”，并把“白色矩形块、空白方框、占位方块”列入负面词。
- **卡点不平均化**：用户给了秒数就严格用；默认 1.25/2.95/4.40/6.55 只在用户未指定时长时才等比缩放。
