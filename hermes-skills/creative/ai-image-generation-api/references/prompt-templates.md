# 生图提示词模板库 + 结构

## 结构公式(9 段,顺序别乱)
`题材锚定 → 主体 → 服装 → 场景 → 光线 → 道具 → 质感 → 防AI痕 → 构图+画质`

| 段 | 作用 | 例 |
|---|---|---|
| 题材锚定 | 定"摄影"而非"插画/AI画" | 专业婚纱摄影照片 / 标准证件照 / 电商主图 |
| 主体 | 人物+数量+族裔 | 一对年轻中国情侣 / 一位年轻中国女性 |
| 服装 | 具体到材质款式 | 精致白色拖尾婚纱 / 深黑色西装外套内搭白衬衫系领带 |
| 场景 | 地点+地形 | 海边悬崖草坪 / 现代极简写字楼落地窗前 |
| 光线 | 出氛围的关键 | 日落金色逆光 / 正面均匀柔光无阴影 |
| 道具 | 丰富度 | 白色花艺拱门 / 手持团扇 |
| 质感 | 调色风格 | 电影感色调 / 韩系清新奶油色调 |
| 防AI痕 | 治塑料皮肤 | 皮肤质感真实自然 / 真实照片质感 |
| 构图+画质 | 收尾强调 | 构图大气唯美,超高清细节 |

## 人像一致性提示词模板(核心)
在场景描述外**必须叠加 4 段声明**,缺一段就翻车:

```
参考照片中的是一位{面部特征描述}(注意:参考图是正面照)。
请保持她的面部特征、五官、脸型、发型完全一致、可清晰辨识为同一人,
将她置于以下场景:{场景描述}。
头部必须随身体一起转向,不要把脸扭回正面,保持{3/4 侧 / 90° 侧}面角度下的自然长相。
真人实拍质感,不要动漫化,不要改变五官比例和脸型,不要过度美颜磨皮。
```

实测:不写"头部随身体转"→ 侧身姿势配正脸(用户明确指出的违和感);写上后 gpt-image-2 与 seedream-5-0-pro 都能转出侧面。根治方案仍是多角度参考图。

## 证件照模板
```
标准证件照:参考照片中是一位{面部特征},请保持他的面部特征、五官、脸型、发型完全一致,生成他的正式证件照。
要求:人物正面直视镜头、头部端正不倾斜,双肩水平对称,嘴唇自然闭合(原照片微张,须闭合),
表情自然平和端庄,头部占画面上部约三分之二,专业证件照正面均匀柔光,面部无阴影无高光过曝,
眼睛清晰有神,{纯白/纯蓝/纯红}色背景干净无杂物,穿{服装},高清真实照片质感,
严格保持本人长相,不得改变五官比例和脸型,不要过度美颜磨皮。
```
- size: `1184x1664`(5:7,16 的倍数)
- 服装套装:深黑西装+白衬衫领带 / 白衬衫+深色领带 / 简洁白衬衫
- 底色:白底(简历/签证)、蓝底(国内办事最常用)、红底(部分证件)
- 交付:自动裁 一寸 295×413、二寸 413×579(LANCZOS,JPEG q95)

## 违禁词过滤表(整任务级拒绝,必须拦)
`酒`、`酒红色`、`微醺`、`酒吧`、`红酒`、`高脚凳` + 酒精氛围词
→ 替换:酒红色→深红色;酒吧/红酒杯→城市高层餐厅、手持水杯;微醺夜色→夜色氛围光
