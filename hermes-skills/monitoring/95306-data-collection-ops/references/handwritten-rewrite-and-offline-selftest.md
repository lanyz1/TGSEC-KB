# 手搓重写采集端 + 离线假传输层自测

## 何时用

- 用户说「不信（AI）写的代码 / 手搓一遍 / 这代码没法读」⇒ 目标不是逐行复刻旧码,而是**按接口事实重写一版能逐行读的最小实现**,行为等价(分片/字段/窗口口径逐字一致)。
- 任何改动采集端/传输层/解析层的任务:**改完先在离线自测里跑绿,再谈上机**。

## 离线自测(每次改完必跑,绿了才谈上机)

```
python -m compileall -q collector tools && python tools/offline_run.py   # 退出码 0 = 全绿
```

- **桩打在传输原语 `Http.raw` 这一层,不要打 `json_raw`**:替换 `raw` 后 JSON 解析、统计记账、预算闸仍然是真的;替换 `json_raw` 会把这三层一起跳过。
- **假层必须复刻 `raw` 的记账**(`stat["req"]+=1`、`by_kind`、business 预算消耗),否则统计/预算两层在离线环境永远测不到。
- 桩样本要覆盖平台真实刁钻形态:公告 HTML **无换行**、**最后一个包件后面没有结束标记**、账号跨分片、企业名只差几个字、同一路径重复请求。
- 断言分四类:①产物落盘(逐个文件存在 + 字段值)②匹配精度(正命中 **且**含糊名必须不命中)③分片归属(别的分片账号不得被认领)④传输层单元(预算用尽 `-2`;本地连不通 `-1` 而不是抛异常)。
- **本机永不直连目标**:自测结束打印真实请求数(桩替换后应为 0)。

## 重写里最常真出的 bug(离线自测抓过,等价实现都会再犯)

- **正则 lookahead 丢最后一段**:`(.*?)(?=第\d{3}包|END)` 这种用"后继"当结束标记的写法,**最后一块后面没有后继 ⇒ 整块消失**。改法:`finditer` 取每段 start,按 `[start_i, start_{i+1})` 切片,最后一块切到末尾。
- **模糊匹配必须有长度闸 + 唯一性**:4 字简称能"包含于"一堆全称 ⇒ `len>=sub_min_len` 且**只唯一命中才采用**。
- **本地哨兵污染风控**:本地短路(cooldown/budget)若也带 `code=100` 之类平台语义,状态机就会把它们计成"平台限流" ⇒ 冷却永远出不来。哨兵用独立键(`_local`)+ 风控记账里提前 `return`。
- **`ConfigParser` 两个坑**:`inline_comment_prefixes=(";",)` 与 `interpolation=None` **必须在构造时传**(构造后赋值不生效);value 含 `%`(JSON 模板/URL)不开 `interpolation=None` 会当插值语法报错;`;` 前要有空格才被识别成注释(`k = 5;x` 会把注释带进值)。
- **`@property` 当方法调**(`self.has_ctx()`),只在运行时炸,`compileall` 查不出 ⇒ 这正是必须跑离线自测的理由。
- **造测试数据把变化位放低位**:`%12` 这类取模,变化位放高位会被模数放大步长 ⇒ 永远取不到目标余数。

## 测试自身的 5 个坑(都踩过)

1. 传输层单元用例要在**挂桩之前**跑,否则测到的是桩。
2. 落盘有节流(秒级 `min_gap`)时,**多轮紧连着跑,第二轮状态不落盘** ⇒ 断言读到上一轮的值(实况:审计档位读到 base 而日志已是 deep)。要么 force 保存,要么 sleep 过节流窗。
3. 轮次开头会 `reset_budget()` ⇒ 想测"预算耗尽"要改**配置取值**(monkeypatch conf getter),不要在运行时设。
4. 多轮跑同一路径会把同一产物写多次 ⇒ 断言写 `>=1 且全部等于期望值`,别写 `==1`。
5. 断言"平台语义"(档位/状态/命中名单),不要断言日志字串。

## 改多处调用点的手法

- 一次 patch 只改一处语义;**别在同一 patch 里同时动 `def` 行和它的 docstring**(会并成一行 → SyntaxError),改完立刻 `compileall`。
- 重命名/收尾时优先消掉硬编码(路径、预算、私有成员直取),顺手把命名写清楚(`any_st()` → `pick_ticket()`)。

## ★与线上对拍:必核的四个口径(每个都能造成静默丢数据/状态翻转)

1. **归集键**:`pack_map.enterprises` 键 = **账号 uid**,不是企业名。线上 `bk_write.py`/`merger.py` 按账号取数,键写错 = 整条读不到(线上还专门做了"单位名键→账号键"归一;自己写的库里留单位名键就是定时炸弹)。
2. **新旧判定用观测时间,不用票时间**:记录里存来源副本 mtime(`_obs`),并库时打点;判据 `_is_newer` 只看它。**用票时间会原样复现线上 v9.36 修过的坑** —— 12 台副本票登录时间几乎全同,`>=` 让最后扫到的陈旧副本赢 ⇒ 池内审核状态随机翻转、推送与表格相位相反。再叠一条:**同观测时间严格保留池内值(`>` 而非 `>=`)**,否则同窗并库来回改、并库计数失去"有没有变化"的意义。
3. **回填字段集逐字一致**:线上 `_merge_ev` 回填企业 7 字段 + 包件 10 字段;自己定义的字段集少一个键,那个字段的历史数据就在并库时被静默丢掉。线上真实键名:企业 `账号/用户/单位/ST/时间/统一社会信用代码/来源/报名时间_平台`;包件 `packCode/packName/保证金/报价模式/物资条数/审核状态/审核码/审核时间/报名时间/来源`。
4. **18 列 CSV 的"统一信用代码"线上一直写空串**(merger 里硬编码 `""`),真值在 `统一社会信用代码` 键下(全量历史导入/8515 链接写的是这个键)⇒ 出表两种键名都认,否则这列永远空。

## 对拍/自测新抓出的 bug(等价重写都会再犯)

- **配置自检"按段判存在"是错的**:采集端与主控侧共用解析器,而 `[paths]/[shard]` 段名两边都有、只是键不同 ⇒ 按 `has_section` 判会把对侧 ini 判成非法配置(连带采集端自己的 ini 也被拒)。**按 key 判**(`has_option`),段缺失跳过而不是报错。
- **并库计数虚高 = 空转写盘**:只有真变了才写(`if hits:`),否则每轮刷 mtime,"有没有更新"再也看不出来。**幂等断言**:同一批数据再并一次必须报 0 更新。
- **`re.sub` 的替换串里放 Windows 路径会炸**:替换串按正则转义处理,`C:\Users` 的 `\U` 直接 `bad escape`。**用 `lambda m, k=key, v=val:` 传参**返回替换文本(顺带避开 for 循环里的闭包晚绑定 —— `"%s = %s" % (key, val)` 在循环里会捕获最后一轮的值)。
- 属性名笔误(私有成员 `self._cp` 写成 `self.cp`)只在运行时炸,`compileall` 查不出 ⇒ 这也是必须跑自测的理由。

### 落盘 / dry-run / 锁三处硬化（只在「进程被杀」或「两个实例」时才暴露）

- **凡「另一个进程会读」的产物一律原子写**（temp+fsync+`os.replace`）。审计姿势：`grep -rn "open(.*[\"']w" collector master bot` 逐处问「这文件被谁读」，只有原子写实现内部（写 tmp 文件）合法。真踩过的三处：`targets.py save()` 整体覆盖、`bk_worker.py save()` 三产物、`merge.py` 的 18 列汇总 CSV。
- **远端单文件裸跑的入口自带 `_atomic_json`**，不要 `from collector.store import atomic_json`（采集机上没包）。
- **多腿写同一份 json ⇒ 字段级非空优先合并**：后写的腿字段更少（公告腿只有 `notTitle` 那几项），直接覆盖会把 `sellEnddate` 抹成空 ⇒ 阶段误判「待竞价」。
- **dry-run 必须零网络 + 零落盘**：一轮正常流程含**建会话**动作（收割票 → `login`/`serviceTicket`），所以零网络模式只打印计划、判断全来自本地 conf/状态文件/产物目录；要发请求的模式单独命名（`--dry-run-net`）并在启动横幅写明「会建会话」。
- **落盘闸放写原语内部，不要逐函数加参数**：`Store` 之外还有十余处直调 `atomic_json`（audit/gapfill/targets 的队列与样例），加参数必漏。做法 = 模块级 `_DRY={"on":False}` + `set_dry()` + `is_dry()`，`atomic_json`/`atomic_text` 首行短路，`Store._dry()` 查 `self.dry or is_dry()`；dry 模式连产物目录都不建。
- **CLI 三模式**：常驻（无参）/ `--once`（跑一轮退出，割接验证）/ `--dry-run`（零网络零落盘）/ `--dry-run-net`（发请求不落盘）。
- **单实例 `flock` 只在会写盘的模式抢**，抢不到 `sys.exit(3)`，绝不双写（两实例同时写 `/tmp/targets` 与状态文件 ⇒ 票池互相覆盖、产物半新半旧）；**锁的文件对象必须留引用**（`app._lock_fh = fh`）—— 被回收即 `close()` 静默放锁（经典坑：看起来锁住了其实没有）。
- **部署指纹按内容算、不看 mtime**：对 `collector/master/bot` 下按路径排序的（相对路径+内容）算 sha1 取前 16 位；两侧一致 = 没有漏同步（tar/scp 会改 mtime，内容不变）。`--selftest`（离线）打印：python 版本 / 代码指纹 / 锁路径 / conf 权限（组或他人可读要报警）。

## 差异对比交付结构(用户要"对比差异发给我"时)
