## 卖家端审核流模式(2026-08-06 落地,可复用)
用户要求"XX 修改需提交管理端审核"时的标准实现(commit df7baad):① 新模型 `SellerChangeRequest`(storeId/requestType/currentValue/newValue/status=pending_review|approved|rejected/submittedByEmail/reviewedByAdminId/reviewNote/submittedAt/reviewedAt),同类型同时只允许一条 pending;② 卖家端 API POST 提交(校验值变化/长度/重复 pending)+ 管理端 GET 列表 + POST [id] 审核(事务:approved 时更新真源字段 User.displayName / Store.name + 写 NotificationMessage 通知卖家;rejected 只通知);③ 卖家端输入框 pending 时 disabled + 橙色徽章"审核中:新值" + 保存按钮变"变更审核中",提交后表单回滚到当前生效值;④ 管理端页 `/admin/change-reviews` + 侧栏"审核管理"组加项,表格行内同意/驳回+备注。**通知一律 `notificationMessage.create({status:"sent",sentAt})` 走铃铛/消息中心**。
