## 卖家端\"删 UI 元素\"工作流(2026-08-06 多次出现)
用户说\"XX 删掉/这个删除\"(提示条/某行/某按钮)时的标准动作:**① 删 JSX 元素(连同其 state/函数/import 一并清理,tsc noUnusedLocals 未开但保持整洁);② 同步删 translations.ts 里对应的 zh+en 两个翻译键(不留死键);③ tsc EXIT 0**。本会话已按此删:密码卡\"频繁操作会被限流 60 秒\"提示、通知偏好\"营销推广\"行、店铺主体卡\"主体信息与入驻资料自动同步...变更待接\"提示条、保证金 tab 重复三列。**用户删 UI 的言下之意常是\"页面已有信息重复\"(如转回面板/保证金 tab 的数字总览卡已有)——先看页面别处是否已展示同一信息,确认是\"删重复\"而非\"删功能\"**。
