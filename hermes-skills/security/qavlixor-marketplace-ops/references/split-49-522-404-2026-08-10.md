## 服务器 522 / "全部404"事故排查（2026-08-10 实录，非攻击判定）
用户报"被攻击/全挂了"时**先验证再下结论**：①外网 curl qavlixor.com → ②本机 3000 → ③`pm2 list`（uptime 短=刚重启）→ ④`tail /var/log/nginx/error.log`（`connect() failed 111`=实例挂、`upstream prematurely closed`=卡顿）→ ⑤`last reboot`+`who -b`（**无 shutdown 记录的 reboot = 云厂商看护硬重启**，宕机检测自动拉起）→ ⑥`free -m`（**swap=0 时内存峰值=系统无响应=522 高危**）→ ⑦access log 确认 Cloudflare IP 请求正常。**时间线重建法**：用户截图时间 vs uptime vs error log 时间戳拼出事故链。**预防（已落地）**：swap 4GB（`fallocate -l 4G /swapfile` + fstab 持久化）+ `pm2 restart <id> --max-memory-restart 1600M` + `pm2 save`。完整实录见 `references/server-incident-2026-08-10.md`。
