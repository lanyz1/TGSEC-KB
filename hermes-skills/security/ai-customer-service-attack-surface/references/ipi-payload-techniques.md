# 间接注入(IDPI)22 种在野 payload 技术

来源:Palo Alto Unit 42《Fooling AI Agents: Web-Based Indirect Prompt Injection Observed in the Wild》在野遥测分类。
适用:目标 AI 会读第三方内容(网页 / 文件 / 工单 / issue / 日历 / 文件名 / EXIF)时,用来构造隐蔽 payload。

---

## A. 投递隐藏(concealment methods)—— 让人和视觉检查看不到

| 技术 | 做法 |
|---|---|
| **零尺寸 / 透明** | `font-size:0`、`opacity:0`、`height:0`、`width:0`、白底白字 `color:#fff` |
| **CSS 抑制** | `display:none`、`visibility:hidden`、`position:absolute;left:-9999px`、`text-indent:-9999px` |
| **HTML 属性藏匿** | 塞进 `title=` `alt=` `aria-label=` `data-*`、HTML 注释 `<!-- -->` |
| **运行时动态注入** | JS 在 LLM 抓取那一刻才写入(静态扫描/快照看不到) |
| **独立区块** | 放页面底部 / 侧栏 / 评论区,人工审阅易跳过 |

**要点**:同一页面**同时用多种投递方式**。只要一种被 LLM 读到就成功,而视觉检查者只看到无害页面。

---

## B. 指令混淆(instruction obfuscation)—— 让过滤器与关键词匹配失效

| 技术 | 做法 | 绕过对象 |
|---|---|---|
| **零宽字符插入** | 字母间插 `U+200B` `U+200C` `U+200D` `U+FEFF`;`"Sale"` → `"S[ZWSP]a[ZWSP]l[ZWSP]e"` | 关键词匹配 |
| **同形字替换 (homoglyph)** | 西里尔 `а` / 希腊 `ο` 替换拉丁 `a` / `o` | 关键词过滤 |
| **Payload 拆分 (payload splitting)** | 一条命令拆到多个 HTML 元素;逐元素扫描器查无恶意,LLM 读的是 `innerText` **聚合结果** | 逐元素扫描器 |
| **乱码文本 (garbled text)** | 异常标点 + 碎片化措辞 | 语义检测 |
| **Unicode 双向覆盖** | `U+202E` 右到左覆盖:显示无害,语义保留 | 人类审阅 |
| **多语言重复** | 同一命令用英/法/中/俄/希伯来语重复;专打多语言能力,英文版被拦也能命中 | 单语安全策略 |
| **JSON / 语法注入** | 用 `}}` 冲出当前数据上下文,注入伪造键值对 | 结构化 prompt 边界 |
| **社工框定** | 把恶意指令包装成紧急 / 合规 / 与用户目标一致 | 安全护栏 |

## C. 在野攻击意图(2026 实测)

- AI **广告审核规避**(首次在野观测)
- SEO 操纵 + 假冒知名博彩平台的钓鱼站推广
- **数据销毁**(递归删除文件)
- **拒绝服务**
- **未授权交易**:强制 PayPal 转账 $5,000、Stripe 订阅欺诈
- 敏感信息外带(API key)
- **系统提示词泄露**
- 招聘筛选偏见注入

## E. 落地用法

1. **找入口**:目标 AI 能读的一切 —— 客服收件箱、工单、上传文档、抓取源、GitHub issue/PR、日历邀请、共享文档、**文件名**、图片 EXIF。
2. **选投递方式**:按载体选 A 组技术(网页用 CSS;文档用零宽;文件名用同形字)。
3. **选混淆方式**:按对方过滤强度选 B 组(弱 → 社工框定;中 → 零宽/同形字;强 → payload 拆分 + 多语言重复)。
4. **护栏补刀**:GitHub 案例中,加入关键词 **"Additionally"** 让模型"重新框定输出而不是拒绝"。这类软性词值得单独做一轮测试。
5. **验证**:观察 AI 输出是否出现你注入的内容 / 是否执行了你要求的动作。

---

## F. 防御(用于判断目标是否已加固)

- **Spotlighting**:把不可信文本与受信指令显式分隔(最早且有效的手段之一)
- **Instruction hierarchy**:指令分层,低优先级来源不能覆盖高优先级
- 对抗训练
- 外部内容一律当**数据**,不当**命令**
- 工具调用强制审批 + 高低权限分级
- 模型输出后置安全校验
- 可执行动作强制人工确认

> 若目标**没有任何内容来源标记、没有指令分层、工具调用无审批** → 注入面全开。
