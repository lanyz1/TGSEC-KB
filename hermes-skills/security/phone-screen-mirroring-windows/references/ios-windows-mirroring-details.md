# 各方案详细步骤与定价（2026-08 核实）

## 1. 爱思助手「实时屏幕」（免费，有线为主）
1. 官网 https://www.i4.cn/ 下载 PC 版（认准蓝色闪电图标，防下到推广捆绑包）
2. 原装/MFi 数据线连接 → 手机弹"信任此电脑"点信任、输锁屏密码
3. 爱思助手 → 工具箱 → 实时屏幕（部分版本在顶部图标）
4. 首次会提示装投屏驱动，跟着弹窗允许
5. 鼠标左键=手指点击；先点画面里的输入框再用电脑键盘打字
6. 无线模式：同一 WiFi，iPhone 控制中心 → 屏幕镜像 → 选"爱思投屏 xxx"
- 注意：爱思助手本体「实时屏幕」支持键鼠操控；独立「爱思投屏」App 有的版本仅镜像不能反控（版本差异，实测为准）

## 2. 傲软投屏 ApowerMirror（反控 iPhone，付费）
前置：Windows 10 1803+、iOS 13+、**电脑蓝牙 BLE（5.0+）**、iPhone 与电脑同一 WiFi
1. 电脑装傲软投屏 + iPhone App Store 搜"傲软投屏"（免费下载）
2. 投屏：iPhone 控制中心 → 屏幕镜像 → 选电脑
3. 电脑端右侧工具栏打开**"反控苹果手机"**开关（按钮变蓝）
4. iPhone：设置 → 辅助功能 → 触控 → **辅助触控** 打开（小白点）
5. 电脑+手机蓝牙都打开，手机蓝牙列表找电脑名**配对**（出现两个同名设备就两个都连；配对弹窗两边都点允许）
6. 配对成功即能鼠标控制；输入框键盘收起=连接成功
- 卡顿调鼠标跟踪速度：iPhone 设置 → 通用 → 触控板与鼠标 → 跟踪速度 6
- 价格：App 内购 360分钟 ¥28 / 季度 ¥58 / 年度 ¥88

## 3. AirDroid Cast（反控 iPhone，付费）
- 电脑桌面版 + 手机 App，同一 WiFi 免费投屏；**反控/跨网需高级会员**（约 ¥30/月档）
- 三种连接：① AirPlay：控制中心→屏幕镜像→选"AirDroid Cast-xxx" ② USB 直连（高清低延迟）③ 扫码/投屏码（可跨网远程）
- 注意：蓝牙需要支持 peripheral advertising 的 BLE 适配器

## 4. LetsView 幕享（免费，仅看）
- 完全免费无线投屏，不能反控。手机控制中心→屏幕镜像→选电脑名

## 5. 微软 Phone Link（手机连接）
- iPhone 仅：通知、短信（无群聊/图片/视频）、电话、通讯录、电量
- **不支持看屏幕、不支持操控** → 需求是投屏/控制时直接排除

## 6. 官方但用不了的路
- iOS 18「iPhone 镜像」：免费完美，**仅 Mac（macOS 15+ 同 Apple ID）**
- 越狱 Veency(VNC)：现代 iOS 无公开越狱，不现实

## 系统级前置检查（Windows）
- 反控类方案必须电脑有蓝牙：`Get-PnpDevice -Class Bluetooth`（Realtek/Intel 笔记本自带即够；台式机需 USB 蓝牙适配器，推荐联想 LX1815 或 RTL8761B 模组）
- AirPlay 发现需要 Bonjour/mDNS 服务运行（iTunes 装过即自带）
