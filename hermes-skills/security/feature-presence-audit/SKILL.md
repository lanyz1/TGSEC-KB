# 功能存在性对账（显示 / 空转 / 隐藏 / 死键 / 没做进去）

## 触发
用户说「X 还是没有显示」「是隐藏没显示还是没做进去」「这功能不是早就有吗」「升级后 X 不见了」。

## 铁律
- **字面词零命中 ≠ 功能不存在，也 ≠ 功能存在**。必须多面对账后再下结论。
- **结论词表先定义再使用**：`显示且真跑` / `显示但空转(只回执)` / `条件渲染` / `隐藏(注册了没人渲染)` / `死键(有按钮无 handler)` / `没做进去(两边都无)`。混着说等于没答。
- **不许把一次 grep 说成结论**。用户问的是二选一，答案必须落到上述词表里的某一个，并附可复现证据。

## 步骤

### 1 词面搜索（含被忽略文件）
- 用 `grep -rIn "<词>" . --exclude-dir=.git --exclude-dir=__pycache__`，**不要只搜 .py/.md**：老代码拆分段、知识库 dump、备份目录常是 `.txt`，走索引式搜索会漏。
- 命中要读上下文判语义：`导入` 在 Python 里几乎全是 `import`；`add`/`new` 类词同理。**同词不同义要明说，别把 import 当功能命中**。
- 同时搜同义面（用户的口头名 ≠ 代码里的键名：补采/补录/入库/加项目/手动/addproj）。

### 2 结构化双向对账（核心）
枚举两套集合并求差集：
- (a) **真上屏**的 UI 元素（callback / 路由 / 按钮 / 菜单项）——逐块渲染面板抓取，不是读源码「应该有」。
- (b) **已注册**的 handler / 路由前缀 / 分发表。
- 差集语义：注册未渲染 = 隐藏候选；元素无 handler = 死键；两者皆无 = 没做进去。

### 3 权限差分
同一批界面用「管理员/高权」与「普通用户/低权」两种身份各渲染一遍取差集。差集应只落在授权、运维、跳板类入口上；**差集里出现用户要的功能，才是真「对他隐藏」**。

### 4 部署对齐（本地写了 ≠ 线上有）
- 取线上真树（软链 `readlink -f` 到实际目录），同一条 `grep -n "<按钮文字>"` 在本地与线上各取一次，**行号一致**才算在线。
- **整目录哈希不相等 ≠ 树漂移**：部署侧可能是 CRLF（远端 grep 输出里出现 `\r`）、本地 LF，哈希天然不同。判漂移按行级锚点对比或先换行归一化；否则会把「已上线」误判成「没上线」。

### 5 需求历史检索（用户是否真的提过）
查会话库确认这需求有没有出现在历史里、我有没有承诺过 —— 见 `references/session-history-search.md`。结论口径：**只有 user 角色命中、且排除当前会话后才算「历史上真的提过」**；assistant 自述命中多半是本次取证片段在自证。

### 6 老版本 / 老单体对照（重写割接丢的通常是动作）
重写后的「功能不见」多半不是藏了按钮，而是**动作被换掉或丢参数**：
- 查**别名表/兼容表**（旧键 → 新键）。别名让老消息里的按钮仍可点，但语义与参数可能已丢 ⇒ 顺着别名走到新 handler，逐行确认参数有没有真被使用。
- 查**写动作是否被降级为回执**：写类命令的 docstring 常自己声明「属主控/后端侧的运维动作（消费端是只读的，不代跑）」，再叠加一层开关（如 `apply_enable`）。
- 查**旧脚本是否还活着**（老单体源码、机器上的老脚本）——能力在而没接入口，就是「没做进去」，不是「做不到」。
- 报告落法：「老版有 X、新版没做进去（按钮显示但丢参数/退化成回执）」+ 新版架构里的等价落点。

## 交付格式（用户要的成品形状）
1. **结论先行**一句话（落到词表里的某一个）。
2. **证据表**：每行一条 + 出处（`文件:行号` / 命令 / 返回摘要），可被复核。
3. **老版/新版对照表**（按钮、动作、参数、开关）。
4. **交付件**：可对照的清单文件（如界面元素全清单 md，管理员/普通用户两栏），落产物目录 + 桌面。
5. **修复方案分档**：A 正解（走新架构、不破既有红线）/ B 最小改动但不解决（说清为什么不解决）/ C 用户可能是另一条线。
6. **动生产前停下等点头**：对账本身全程只读，不给生产加任何改动；方案列出后等用户点名再实施。

## Pitfalls
- **别用「未覆盖」打包票**：写明「这次没查到」与「确实不存在」的区别，并列出未覆盖面。
- **别只 print 一行**：取证探针输出会被压缩器截断 ⇒ 用集合长度 + 排序列表 + 落盘日志，一次拿全。
- **探针脚本自身的笔误也算失败一轮**：import 段写多余表达式、构造器参数少传会直接炸；跑前自检这两处。
- **权限差异不是「隐藏」**：对普通用户不可见是产品设计还是缺陷，要靠权限差分表说清，别一句「被隐藏了」收尾。
