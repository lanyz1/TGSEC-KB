# 列表端点产出测量(能不能拖、能拖多少)

适用:找到一个未授权/低权可读的列表端点,要判断它是"固定一页"还是"可枚举全库"。

## 1. 先判是不是固定页(交集法)

同一请求连发 6 次,取 6 次返回 id 的**交集** = 稳定集。

| 稳定集 | 结论 |
|---|---|
| ≈ 满页(例:20 条里 15 条固定) | **固定页** —— 返回的是同一批(排序靠前的热门项) |
| ≈ 0 且各次集合差异大 | **随机抽样** ⇒ 反复请求即可累积全库 |

**只看交集,不看"第一条 id 变没变"** —— 无参数时基线本身就在动(新数据插入、排序抖动),看第一条会误判。

## 2. 有分页才有全量钥匙(交集法判分页)

逐个发候选分页/游标参数,每次算"返回集 ∩ 稳定集":

| 交集 | 结论 |
|---|---|
| ≈ 稳定集 | 参数被服务端**忽略**,不是分页 |
| ≈ 0 | **游标真的生效** ← 全量钥匙 |

候选名:`page` `page_size` `limit` `offset` `start` `size` `cursor` `last_id` `max_id` `min_id` `before` `after` `since_id` `id_lt` `id_gt` `create_time` `ts` `next` `token`

**不要**用"返回条数变了没"判断 —— 满页都是 20 条,看不出区别。

## 3. 没有分页 ⇒ 测筛选参数,做组合枚举

候选维度按目标业务猜:平台 / 类型 / 渠道 / 状态 / 时间区间 / 金额区间 / 地域。

单发判定哪些是**真参数**:

| 响应 | 结论 |
|---|---|
| `422 Invalid value.` | 参数被识别 + 值域有限(可二分值域,如 `platform=10` 报错 ⇒ 值域 1–9) |
| 条目数 **< 满页** | 筛选真生效 |
| 满页且与基线重合 | 参数被忽略 |

确认后再做**笛卡尔积枚举**,限速串行。

## 4. 报告写法:先量数,再开口

跑一个**可行性规模**的批次(约 100 个限速请求),产出实测数:

```
约 N 个请求 → M 条唯一记录 / K 个不同实体 / 合计统计量
```

**禁止**在没有实测数时说"可拖全库""影响巨大"。

## 5. 纪律

- 批量枚举属**批量动作**:规模与速率先问用户,跑时限速,随时可停。
- 落盘原始数据 + 统计脚本,报告里给**可复现命令**而不是结论截图。
- 去重、计数、排序用代码做,不靠眼睛数。
- 已发现的敏感字段要**实证敏感度**:字段名叫得响不等于真敏感 —— 拿到样本先判断内容是不是公开物(分享卡片/占位图),再决定是否写进报告。
