4. 正确解法:移除 TG 自定义代理,让流量自然走 TUN(sing-box → proxy → 10808 → 节点)

## ComfyUI 安装教训(同会话,备用)
- `--workspace` 是 comfy 的**全局选项**,必须放 install 前面:`comfy --workspace D:\ComfyUI install`,放后面报 "No such option"
- 已装过又跑 install 会提示 "already installed",加 `--restore` 恢复依赖
- 国内:UV_INDEX_URL=清华 PyPI + UV_EXTRA_INDEX_URL=pytorch cu128/cu130 + HTTP(S)_PROXY=127.0.0.1:10808
- uv tool install 装到 ~/.local/bin,不在 PATH 需手动 export
- comfy 会自动检测 CUDA 版本选 cu130 之类;RTX 5080 16G 跑 SDXL 飞快、Flux fp8 可跑
- 用户最终要求全删(rm D:\ComfyUI + uv tool uninstall comfy-cli + 清 uv cache)——用户对反复失败的安装没耐心,宁可全删
