# 代办服务合规 + 附件电子化签署（2026-08 新增，与用户敲定）

## 一、代办执照服务（09_代办服务确认单）
用户模式：学员的美国营业执照由用户对接代办公司办理，用户赚差价。

### 法律定性：居间（民法典961-965条）
- 赚差价=服务费，合法（定价自由）
- **分界线（962条）**：居间人应如实报告。对学员谎称"代办公司收1500"（实际800）=隐瞒真实信息→可被拒付报酬+索赔。**明码标价即洗白**："代办机构费用 X + 甲方服务费 Y = 合计 Z"，学员知情，差价合法。

### 三个前提（守住就没事）
1. 透明性：不谎报代办机构价格，费用构成明示
2. 代办公司质量：推荐前先验证（实际办过几单、执照真伪、能否过平台审核）——学员被野鸡代办坑→找推荐人担居间责任
3. 用途合法：明知执照用于洗钱/诈骗/违法收款仍代办→帮信风险；正常开店用途无责

### 09_代办服务确认单内容（已交付）
- 编号 + 关联主合同编号
- 服务内容勾选（美国公司注册/营业执照EIN/其他）
- **费用透明列示**：代办机构费用 + 甲方服务费 分开填（人民币/USDT均可，支付方式勾选）
- 风险提示与不承诺：不承诺100%办成（未办成退款规则勾选）、不承诺平台过审（取决于平台规则）、用途合法承诺（防帮信）
- 与主合同关系：为主合同服务内容的一部分（主合同2.3已扩为"资源对接：含证照代办对接"）

## 二、附件1+2 电子化签署（免邮寄）
痛点：附件一《月度经营结算报表》(每月)、附件二《服务交付确认单》(每次指导后) 纸质邮寄签字太麻烦。

### 法律依据
- 《电子签名法》13条：可靠电子签名与手写签名同等效力（正规签约平台走这套）
- 最高法证据规定：微信聊天记录/电子邮件/在线表格=合法电子证据
- **主合同 2.5 已把"聊天记录"纳入履约凭证**——电子化天然有条款支撑

### 推荐方案（日常免费版）
- **附件一月度报表 → Excel/腾讯文档模板**（格式与主合同4.2纯利润公式一致），学员填好微信发来，甲方微信确认："X月报表已核对，纯利润X，分成Y，确认无误"
- **附件二交付确认 → 微信结构化确认话术**：
  "【服务确认】编号QL-2026-001｜日期｜本次内容：投流账户结构优化(1小时)｜请回复'确认'，未回复视为已接受（合同2.5条）"
- 关键动作：聊天记录永不删除（双备份）；学员微信备注=合同编号+实名

### 正规升级版（可选）
- e签宝/法大大/上上签：实名认证+时间戳+防篡改，证据效力最强，按份收费几元
- 用法：主合同/大额结算确认用平台，日常高频用微信版

### 主合同配套条款（已交付）
11.4 电子方式确认：双方同意结算报表、服务交付确认单等文件可采用微信/电子邮件等电子方式制作发送确认；双方在电子方式中作出的确认（含回复"确认""同意"）具有与书面签署同等法律效力；双方应妥善保存电子记录作为履约凭证。

## 三、身后事推演补充结论（用户咨询过的最坏情形）
- **死后暴雷（平台/厂家在甲方死后才跑路）**：甲方责任在死时已定型（无过错+合同7.5-7.7风险自担+风险告知签字）→ 无责；公司只需"事务性应对"（公告+协助+应诉），不是赔偿责任
- **"死亡+零财产+私钥灭失"组合**：纸面责任清零（刑事追诉终止、追缴执行不能、继承人放弃继承免责），但代价是钱随之灭失——所有"逃责设计"（欠条=虚假诉讼罪、突击转移=坐实预谋）都会把家人/受让人变成共犯；唯一正解=白账经营
- 《致学员的信》按"预写遗言"写：预设"暴雷可能发生在我死后"，内容成立不依赖死亡时点；由继承人在办理继承时转发一次（一次性动作，非接手人）
- 继承人兜底：民法典1145条——无遗嘱执行人时全体继承人=当然遗产管理人，法律自动配人，不需要用户生前安排"接手人"，但需要"文件"（遗嘱+紧急信息卡+交接清单）
