# USDT / 现金 / 税务合规明细

## USDT 在中国大陆的法律地位
- 2021年十部门《关于进一步防范和处置虚拟货币交易炒作风险的通知》：虚拟货币**兑换、买卖、作为支付工具**均属非法金融活动。个人持有灰色（自担风险），但规模化收付/结算=红线
- 跨境 USDT 结算叠加外汇管制：变相外汇买卖，累计 **500万人民币**以上构成非法经营罪（2019两高解释）
- 涉币后公安初查方向改变：不是查"有没有骗人"，而是直接查"资金是否涉非法经营/洗钱/帮信"——**合同解决不了资金合法性问题**
- 合同应对：以人民币计价，USDT 仅作支付方式（保住"主债务是人民币"的定性）；禁止改为"以USDT计价结算"

## 资金流设计（决定性）
- 只允许两种流向：学员→甲方（分成）、甲方→导师（劳务费）。**绝不存在"下线付钱给上线"**
- 甲方绝不做：帮学员换币、代收代付货款、代管账号资金、代持虚拟币（=资金二传手=非法经营+帮信入口）
- 收款：只收能验证来源的 USDT（要求交易所提现记录 TxID）；来源说不清拒收
- 周转：USDT 只付经营成本（厂家货款/平台保证金），钱包不留大额余额

## OTC 变现纪律（最危险环节）
- 渠道：只用主流大交易所内置 P2P，选"商家认证+成交量大的"
- 黑钱信号（任一即取消）：溢价明显高于市价 / 要求转私人账户 / 新号无历史 / 催单急 / 频繁换收款账户
- 小额分批：单笔≤2万，分散 2-3 张卡；专用收款卡（非工资卡/公司卡）
- **避免"快进快出"**：变现收款后勿立即转第三方（跑分特征→推定明知→帮信罪）
- 警戒线：单日>5万、单月>20万 → 暂停自查
- **绝不做线下现金 OTC**（一手交币一手现金）——黑钱终极出口，公安重点打击；"不知情"辩不掉（线下现金=规避监管动作本身推定明知）；无KYC/无订单/无救济，还有抢劫人身风险

## 现金红线
- 分成只走对公转账；现金=账外收入=偷税+证据归零（合同查账权/发票条款全废）+反洗钱标记（大额现金存取5万以上上报）
- "USDT+现金"双无痕资金=地下钱庄/资金盘画像，民事纠纷直接滑向刑事调查
- 学员只有现金：让其存银行再转账（大额存取有上报反而是正常化处理）

## 冻卡处理流程
1. 联系银行确认冻结机关（公安/法院/反诈中心）及原因
2. 备材料：身份证、交易所订单、链上TxID、KYC截图、聊天记录
3. 主动联系如实说明：P2P变现、对手实名认证、对资金来源不知情、配合调查
4. 涉诈资金划扣，其余解冻；不要换卡继续大额变现、不要对抗调查

## 税务（只收USDT）
- 收到 USDT=收入成立：按收取日汇率折算人民币申报；**不变现≠不交税**（这是偷税幻想）
- 推荐路径：部分变现进对公（账实相符）+ 部分周转（要凭证：发票/收据/账单）+ 台账齐全
- 税种：增值税小规模 1%（季度30万内免征）/一般纳税人6%；企税小微利润300万内实际5%；分红个税20%（提现时）；导师劳务费公司代扣代缴（预扣20-40%，年度汇算）
- 例：季度60万收入→增值税0.6万；利润70万→小微3.5万；综合合法税负约14-15%
- 不做 OTC 变现的坑：成本无票→全额交税；账实不符→被问询；虚拟币确认收入规则模糊
- 红线：不申报=逃税罪（累计5万+且占应纳税额10%）；私卡收变现不申报=反洗钱监控；账实不符=税务问询
- 成本要票（厂家/物流/软件/推广），没票=利润虚高

## 公司化注意
- 一人公司财产混同→股东连带：公司账/个人卡严格分开，规模大了做年度审计
- 刑事不因公司豁免：诈骗/非法经营/帮信追的是人（法定代表人照样抓）
- 税务上"用什么币收"不是问题，"收多少报多少"才是
