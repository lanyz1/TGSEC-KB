# 跨境电商合作合同与刑民合规

（带教分成 + 导师制模式，2026-08 与用户逐轮敲定并交付套件）

## 适用场景
- 草拟/审查"带教 + 利润分成"类合作合同（教注册店铺/投流、推厂家、抽纯利分成）
- 用户问刑民风险边界（诈骗 vs 合同纠纷、传销、非法经营、帮信）
- 涉及 USDT/虚拟货币支付、OTC 变现、现金、税务申报
- 合同条款之间的一致性自查（改完必做）

## 核心模式（用户已确定）
- 不收学费，抽学员纯利润分成；**比例一律留空**，签约时随机应变填
- 导师制：学员只付甲方总比例（如30%）；甲方留存 X%、付导师 Y% 劳务费（代扣个税）；**学员永不直接付钱给导师**（一旦"下线付上线"= 层级3级破线）
- 公司主体签约（员工教学=公司履约，主合同加 2.6 委派条款即可，无需额外协议；员工另签保密+竞业防带走学员/厂家资源）
- **灰产环节切割**：购币/买号/海外网络/钱包——全部学员自行准备，甲方不代购、不代注册、不推荐工具、不经手资金。由 **02《学员须知与确认书》第三部分（自助准备清单）**签约时一次性发+签字切割；客服统一话术："工具类问题请参考签约时发的《学员须知与确认书》自行解决"（复制粘贴，零教学成本）
- 已交付套件：`桌面\跨境电商合作合同套件`（00 说明 + 01~08，共9个文件）；**02《学员须知与确认书》= 原02风险告知+06购币指引+10自助清单三合一**（合并原则：按"签署对象+时点"合并——同为学员签约时签的文件才能合；导师协议/月度表单/内部文件不合）。签约只需 01+02，导师学员加03，代办执照加08

## 六条红线（违反=刑事风险）
1. **不承诺收益**（稳赚/保本/月入X万——合同、聊天、朋友圈三处零容忍）
2. **不碰学员的钱**（不代收货款、不帮换币、不碰账号密码资金）
3. **不搞层级**（只抽自己直接带的人，层级永远≤2；画图从自己往下数，任何链条超2个抽成节点即错）
4. **USDT只周转**（变现走大交易所P2P、小额分批、不快进快出、绝无线下现金交易）
5. **现金零容忍**（分成一律对公转账；学员只有现金→让其存银行再转）
6. **收入必申报**（USDT收入按收取日汇率折算人民币；不变现≠不交税）

## 刑事风险地图（6方向）
| 罪名 | 触发 | 堵法 |
|---|---|---|
| 非法经营 | USDT跨境结算/变相换汇累计500万 | 法币优先、不做兑换生意、不帮学员换币、不当资金二传手 |
| 帮信/掩饰隐瞒 | 收到黑钱 | 只收能验证来源的USDT（要求交易所提现记录）、变现不快进快出、专用收款卡 |
| 组织领导传销 | 层级3级+30人 | 合同禁止层级计酬条款 + 层级压扁2级 + 计酬依据=实际经营利润而非人头 |
| 诈骗 | 承诺收益/虚构事实 | 全口径零承诺 + 风险告知书独立签字 + 履约留痕 |
| 非吸 | 预收+承诺回报 | 合同写"不预收任何款项"，收益全来自盈利后分成 |
| 逃税 | 大额不申报 | USDT折算申报，变现进对公 |

**核心认知：刑民界限 = 非法占有目的 + 履约事实。** 大量学员亏钱≠诈骗；"收钱不干事/承诺收益/跑路/突击转移"才是。合同是盾，行为（真教/留痕/不承诺/肯退费）才是根本。口头承诺压不住，微信记录就是证据。

## 灰产环节切割细则（购币/买号/网络/钱包——学员自助原则）

判断标准一句话：**正规可验证的公开渠道可以发（如运营商官方旗舰店），灰产/无法验证的渠道绝不发**。

- **发链接给学员**（客服操作）：只发官方自营店链接，**不挂返佣/淘宝客链接**（吃返佣=利益关联，出事变背书）；话术带一句风险提示留痕
- **代办执照（美国执照）**：居间角色，民法典962条（故意隐瞒/提供虚假情况=拒付报酬+赔偿）。赚差价合法但必须**透明**——09《代办服务确认单》把"代办机构费用+甲方服务费"分开列明码标价；写不承诺办成/不承诺平台过审；学员声明用途合法（防帮信）；选靠谱代办公司（先验证）
- **海外通讯账号**：WhatsApp **+86 无法注册**（收不到验证码），需海外/香港号；正规途径=香港预付卡（运营商官方旗舰店天猫/京东、官网邮寄、过关便利店现买；内地收货+线上实名，全新未激活，避开第三方卖家）；**只买"号码"不买"账号"**（成品号/养号/批量号=灰产）。TG 用 +86 手机号可注册、**无需买号**——学员想"买号"本身是危险信号；TG 卖号市场=黑灰产聚集地，代买=帮信"应当知道"推定+资金经手双雷
- **翻墙/海外网络三档**：个人自用=行政违法（罚款级，一般不刑）；经营/售卖机场=非法经营罪；**推荐/教学员翻墙=刑事风险（红线：不教不推不代购）**。公司自己走正规国际专线（运营商企业专线/跨境组网）；学员自备自担+话术留痕（"我不提供不推荐任何工具"）
- 上述全部由02确认书第三部分一次性切割，签约时发；教学只教经营（选品/投流/厂家），工具问题零教学

## B/C 私下教灰产内容（甲方"不知道"）——牵连三情况与切割
框架对购币/翻墙/账号/办卡**通用**（B 教 C 的翻墙/买号/办卡风险比购币更实——违法属性更明确：翻墙=行政违法明确、买卖账号=断卡行动打击、办卡涉"两卡"）：
- **B 行为定性分级**：口头指路公开信息（"自己去搜教程"）=灰区基本无责；提供工具/代购/代办/推荐渠道=帮信风险；**经手资金**（代收代买）=帮信/掩饰隐瞒，B 直接进刑事区
- **甲方被牵连仅三种**：①授意 B 去教（B=你的工具）②明知而默许（知道不管=放任推定共谋）③体系资金链出现经手人（B 经手 C 的钱，公安顺资金链查）
- **"不知道"的正确用法**：不是装作不知道（出事时 B 一句"他知道"就击穿），而是**发现即制止+留痕**（话术"带教只教经营，工具类问题看02确认书第三部分"）；04 带教记录表月度检查有无"翻墙/买号/办卡/代购"字样=监控台账
- **03 带教协议 4.4 扩展文本**（本session已定、待落文件）：带教仅限经营指导；"乙方不得提供或推荐任何翻墙、VPN等网络工具及服务，不得代购、代办任何账号、电话卡、证照，不得介绍任何相关渠道，不得经手被带教方的任何资金；违反的甲方有权立即解除、取消资格并追回已付报酬"

## 员工企业微信命名规范
- 格式：`公司简称-职务-实名`（如"XX跨境-王老师"）；员工**不用"导师"**（导师=03协议带教人，防身份混淆）
- 避开"金牌/首席/爆单"等夸大词（涉嫌承诺收益，聊天记录截图是将来的把柄）；别用江湖昵称（与公司主体脱钩，诉讼时"这人是谁"说不清）
- 实名>编号；统一头像；昵称注册后不改（改名=证据链断裂）；与 2.5"聊天记录作履约凭证"挂钩——员工企业微信+公司前缀+实名=公司履约的直接证据（私人微信昵称则证据效力弱）

## 关键合同条款（设计意图）
- 1.3/1.4 关系隔离：非劳动/合伙/代理；甲方不接触账号资金
- 2.5 服务交付确认（履约证据，防"收钱不办事"指控）；2.6 委派员工教学
- 4.1/4.6 比例留空；4.6 条件式（有导师留X付Y；无导师全部归甲方；**合计须=4.1总比例**）；4.4 查账权（拒不配合视为认可甲方估算）；4.7 人民币计价 + 4.9 对公账户 + **USDT收款地址**（USDT付不到对公，必须补地址条款）
- 5.3 **渠道使用限制**（勿写"跳单禁止"——与7.5直接交易矛盾；正确版：正常拿货不受限，但不得泄露厂家信息/用于协议外经营/终止后扩展新业务传授他人）；5.5 保密；5.7 禁止层级计酬（**必须加"由甲方支付的带教劳务报酬除外"豁免**，否则误伤导师）
- 7.5/7.6/7.7 资金隔离 + 厂家/平台风险乙方自担（免责三件套；前提：甲方没收返佣、有风险提醒、真履约、自己也是受害者）
- 8.6 不预收；8.7 **债权转让**（无人追债时的兜底：债权可转让第三方，通知乙方即生效——解决"公司瘫痪没人追款"）
- 11.3 附件（附件三=02学员须知与确认书、附件四=03带教协议）随主合同一并签署装订

## 条款一致性自查（本session踩过的6处坑，改完合同必查）
1. 5.3"跳单禁止" vs 7.5"直接交易"矛盾 → 改渠道使用限制版
2. 5.7"不从第三方经营成果提酬"误伤导师劳务费 → 加豁免
3. 4.7 允许USDT vs 4.9 只有对公账户 → 补USDT收款地址
4. 4.6 两个比例 vs 4.1 总比例 → 加"合计应等于"
5. 带教协议缺"带教范围限定"（不得传授购币操作/代购/介绍兑换商/经手资金）→ 补条款
6. 带教协议报酬比例 vs 主合同4.6 → 绑定一致
另：5.5 里旧概念名词（跳单禁止）要随5.3改名同步更新。

## 税务（只收USDT）
- USDT收入=人民币收入，按收取日汇率折算；增值税小规模1%（季度30万内免征）、企税小微实际5%、分红20%、导师劳务代扣代缴
- 推荐"部分变现进对公（账实相符）+ 部分周转（要凭证）+ 台账齐全"；成本尽量要票
- 红线：不申报=逃税罪（5万+且占10%）；私卡收变现款=反洗钱监控；账实不符=被问询
- 明细见 references/usdt-cash-tax-compliance.md

## 身后安排（用户特定，尊重隐私）
用户有心脏病可能随时离世、**无接班人且不准备安排**、家人关系不好、**钱包私钥不留给任何人**。涉及身后事咨询：
- 法律兜底：继承人=法定遗产管理人（民法典1145条自动），遗嘱强制力——不需要"人"也需要"文件"（遗嘱+紧急信息卡+交接清单）
- 死亡终止对个人的刑事追诉（刑诉法16条），但不终止：公司债务、违法所得追缴、继承人限定继承责任
- **留钱给家人的唯一干净工具=保险指定受益人**（身故保险金不算遗产、不用于偿债）；私钥决定钱包资产归宿——不留私钥=资产永久灭失（家人/追缴/学员都拿不到；用户已定：私钥不留给任何人）；"零财产"靠转移制造=把雷埋进家人（家属涉掩饰隐瞒），合法收入花在明处的零财产才干净
- 用户"没有接手人"方案：不需要人，需要文件（遗嘱+紧急信息卡+交接清单）；继承人=法定遗产管理人（民法典1145条自动兜底），债权转让条款（8.7）解决"公司瘫痪没人追分成"
- 不做"金蝉脱壳/虚构债务"式建议（欠条=虚假诉讼罪；突击转移=坐实预谋推定）；唯一正解=合法经营白账

## 生成工具与坑
- 用 docx skill（docx_create.py + JSON spec）。坑①：**自定义样式名避开Word内置**（如 'Title' 报 `document already contains style 'Title'`，改用 ContractTitle/ClauseHead/CNBody 等）；坑②：文件被 Word 打开时保存报 PermissionError（目录出现 `~$` 锁文件）→ 先让用户关闭 Word 再重跑
- 合同编号建议：主合同 `公司简称-年份-序号`（QL-2026-001），带教协议独立前缀（DS-）；一个学员一个号永不复用，台账同步挂编号
- 交付习惯：套件生成到桌面文件夹，每份 docx 用 docx_read --text 验证关键词
- **合并文件技巧**：docx spec 的 blocks 是 dict 列表，用切片拼接合并（`标题行 + risk_blocks[5:23] + 第二部分标题 + coin_guide_blocks[4:22] + ...`），原 blocks 定义保留不动
- **patch 工具坑**：old_string 含重复模式（如"乙方签字行+甲方盖章行+]"）时 fuzzy 匹配可能把内容插到错误位置或产生幻觉 diff——大段插入后用 read_file 确认实际落点，再跑生成
