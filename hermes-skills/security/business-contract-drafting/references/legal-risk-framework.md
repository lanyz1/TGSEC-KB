# 中国合同法律风险框架（分成/带教/加盟类）

浓缩自实战咨询(2026-08)，供草拟合同时直接引用。非法律意见，大额/涉众场景提醒用户请执业律师。

## 诈骗罪 vs 民事合同纠纷
刑法266条，核心两要件：
- **非法占有目的**：收钱时是否打算履约、是否真实履约、事后是否跑路(拉黑/失联/注销收款渠道=推定)
- **虚构事实/隐瞒真相**：承诺虚假收益、虚构能力/资源

判断要点：
- 大量"学员亏钱"本身 ≠ 诈骗；生意亏损是市场风险，公安不会因"学员亏了"立案
- **履约事实(服务交付记录)是排除非法占有目的的最强证据**
- 退款机制存在(未交付部分可退) = 无非法占有目的的证明
- 一边倒合同(只写乙方义务)易被认定为"以合同为名行诈骗之实"
- 合同条款压不住口头承诺：微信聊天/宣传文案中的"保证收益"照样是证据

## 诈骗罪数额标准（两高解释，各地有浮动）
| 档次 | 金额 | 刑期 |
|---|---|---|
| 数额较大 | 3千-1万 | 3年以下 |
| 数额巨大 | 3万-10万 | 3-10年 |
| 数额特别巨大 | 50万+ | 10年以上或无期 |

**多个学员金额累计计算**——50万是生死线。

## 立案机制（涉众）
- 1人报案 → 多被定性民事经济纠纷劝回
- 3-5人联名 → 开始认真初查
- **10人+联名报案 → 公安基本必须立案**（涉众考核压力）
- 初查三看：①宣传承诺(有无保证收益) ②履约事实(有没有真教) ③资金去向
- 人数金额决定"会不会被查"，履约事实决定"查了之后有没有事"

## 非法吸收公众存款
构成要件：公开宣传 + 承诺还本付息/回报 + 向社会不特定对象吸收资金
- 收"投资款/加盟费"并承诺回报 → 非吸风险
- 收"服务费"(真实服务对价) → 一般不构成
- 合同明写"款项系服务对价，非投资款/加盟费/保证金"是第一道防线

## 组织领导传销活动罪（刑法224条之一）
追诉标准：**发展人员30人以上 且 层级3级以上**，对组织者、领导者追刑责。
特征(《禁止传销条例》第7条)：
1. 拉人头：以发展人员数量作为计酬依据
2. 入门费：交钱才能获得加入资格
3. 层级计酬：上线从下线业绩中提取报酬

**合法与传销的分界：计酬依据是"实际经营利润"还是"发展人头数"。**
- 收入 = 自己直接指导/服务对象的真实经营利润 → 合法空间
- 收入 = 发展人数 / 层级返利 / 跨级收益 → 传销定性

## 转介绍/层级结构安全设计铁律
- 层级永远 ≤ 2（顶→中→底），要放大就**横向复制**而非纵向加深
- 任何人只抽**自己直接签约/直接指导**的人，禁跨级收益
- 转介绍只给**一次性固定红包**(不按比例、不持续)——"人头计酬"哪怕按人头给固定金额也是拉人头
- 资金流不经过顶层(顶层不是"抽水机"，角色是旁观者)
- 禁词：团队/体系/下线/团队计酬/管道收益/代理费/加盟费

## 甲方(指导方)被追责的情形清单
按危险度排序，向用户咨询"什么情况会追我"时直接引用：
1. 口头/微信承诺收益 → 欺诈/缔约过失/退费(证据=聊天记录)
2. 实际碰学员账号/资金 → 事实合伙/委托经营，亏损要分担
3. 教违法玩法(刷单/盗图/售假) → 教唆/共同侵权
4. 收分成却不履行指导义务 → 解除+退还已付分成
5. 明知厂家有诈仍推荐(尤其吃回扣) → 居间/缔约过失责任
6. 泄露乙方经营数据(合同须补甲方对等保密义务)
7. 预收费用性质不清(写成"保证金"危险，写"已交付服务的对价"安全)

安全模式定调：**低预收 + 高分成**。纯利分成模式(乙方不赚甲方没钱)天然排除"骗钱动机"，是结构性的民事证据。
