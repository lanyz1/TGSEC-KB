# 市面 TikTok 投流/账号平台调研简表（2026-08-29 web 调研）

给 TikFlow（tiktide.com）做竞品/定位参考。调研来源：知乎/TT123卖家导航/各官网/FastMoss/Kalodata/SocialEcho 软文等（数据为当时公开信息，会过时，用前复核）。

## 生态分类地图
1. **官方**：Ads Manager（三层级广告）、Promote（视频加热 CPM）、Analytics（账号数据）、TikTok Shop Seller Center + LIVE Manager（直播/电商）、Creative Center（爆款素材）
2. **第三方广告管理 SaaS（官方 API 合规）**：AdsPolar（跨境向：跨账户看板+AI投放按实时 ROAS 调预算+素材管理+Shopify 打通）；海外 Smartly.io/Bidalgo/Skai（$2000+/月大客户）
3. **社媒矩阵管理 SaaS（官方 API）**：SocialEcho $10/月起(5账号,AI评论分类/关键词监听)、Hootsuite $99、Sprout Social $249、Later/Buffer $6-25。**共同卖点："官方 API 接入不会封号"**
4. **TikTok Shop 数据平台**：FastMoss（380万+用户/市占率第一，7维数据+广告策略引擎，试用3天→¥99/15天→年费）、Kalodata（300万+用户/跨 TikTok/Amazon/Shopee，7天试用+订阅）、EchoTik、达人精灵、Sorftime（56 个 API/MCP）。**数据来源 = 公开采集+AI 模型估算**（Kalodata 官网免责"成交金额/广告消耗为估算，勿用于佣金结算"）
5. **矩阵/自动化系统（半灰产，与 TikFlow 最像）**：TK云大师（自称 3127 团队/800万账户/2100万发布视频，微信/电话/邮件获客）、Smart BIAI（指纹浏览器+专属 IP 一号一机一 IP，自称 5000+ 账号合规）、引量AI（单日发布 1000+）。开源参考 Prism：TikTok 用**本机浏览器登录→保存 storage state 复用**（与 TikFlow CK 绑定同思路）

## 商业模式（可抄）
- 免费试用 3-7 天引流 → 订阅分档（$10-249/月 按账号数/功能）
- 数据平台会员制（¥99-¥3999/年）
- **代理分销返佣**（FastMoss/Kalodata 都有"代理合作计划"）
- 获客：知乎/公众号软文 + TT123 卖家导航收录 + 卖家社群

## TikFlow 差异化卖点
- 市面矩阵系统要客户提交账号密码/装软件（风险高）；TikFlow = **用户自己抓 CK + 自己代理**（账号不进平台）→ 打"账号安全"卖点
- 差距清单：数据维度（加粉丝增长趋势——免签名接口已验证）、素材管理、订阅收费、代理分销
