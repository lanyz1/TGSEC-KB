## 页面清单(15 个 view,hash 路由 `#/route`)

- **未登录(auth-mode,无侧栏)**: login / register / onboarding(4 步向导)/ status(审核三段进度)
- **后台**: dashboard(工作台)/ products / product-new(4 步表单)/ orders / order-detail / logistics / aftersales / aftersales-detail / messages(三栏聊天)/ funds(双卡 + 7 页签 + 收银台弹窗)/ account

导航角标:订单 12、售后 3、消息 5(>99 显示 99+,0 隐藏)。顶栏「切换账号」→ login。

## 领域规则(演示数据要遵守)

- 金额:全部 USDT;提现手续费 **1.5%**、单笔最低 50;充值/订单/保证金共用收银台(二维码 + 地址 + 倒计时 + TXID 兜底)
- 支付方式 6 种,仅 3 种 USDT 网络(TRC20/ERC20/BEP20)可用,其余 disabled
- 保证金:应缴 500,档位按 GMV,取消率系数;状态 需补缴/待确认/正常
- 售后:售后期 30 天(自签收);商家处理时限 48h;状态 商家处理中/平台介入/已拒绝/已关闭/已退款;平台介入后表单锁定
- 商品:状态 已上架/待审核/已驳回/已下架/草稿;标题 ≤60 字自动翻译 7 语;SKU 表 ≥1 行;主图 1/副图 ≤8/细节长图 ≤12/参数 ≥3 组
- 订单:状态页签 全部/待发货/运输中+已签收/售后中/已完成+已关闭;淘宝式行首灰条(时间+单号+买家);结算 平台佣金 5% + 手续费 1.5%
- 会话状态:进行中/待买家/待商家/待客服/已升级/已关闭;三栏 = 会话列表 + 聊天窗(图片 ≤8MB) + 上下文面板(AI 摘要/商品/订单/快捷操作)
