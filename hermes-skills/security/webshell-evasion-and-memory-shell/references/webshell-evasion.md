# Webshell 免杀（静态 + 流量）

两类目标要**同时**满足，否则传上去也是送样本：

```text
静态免杀：文件不被静态引擎/云查杀认出（去工具格式特征 > 混淆）
流量免杀：交互过程不被流量审计/IDS 认出（工具默认特征必须改）
```

## 静态：四层手法（由浅到深）

| 层 | 手法 | 要点 |
|----|------|------|
| 字符串变换 | `strrev`、`str_rot13`、base64/gzinflate、异或、`chr()` 拼接 | 只用 base64 早已入库；**多种混合**且密钥常量不固定 |
| 函数特性 | 变量函数 `$f='assert';$f(...)`、`call_user_func`、`array_map`、`usort` 回调、`include` 执行 | 敏感函数名不要以明文与调用同现 |
| 类特性 | 魔术方法 `__destruct/__invoke/__call` 触发、`spl_autoload_register`、原生类 `ReflectionFunction` | 把执行点藏进"看起来正常"的类方法 |
| 混合 | 以上叠加 + 注释/空行/大小写/魔术常量 | 最终过本地引擎（D盾/河马/长亭/云查杀 + VT） |

**去工具格式特征**（最关键，多数人漏）：变量名、函数定义顺序、空行与缩进风格、`echo` 数量
——魔改痕迹比混淆更容易被认出"这是某某工具的马"。

## 特征码二分定位

```text
① 原始马丢静态引擎 → 报毒
② 二分删除代码块（保留能跑的最小集）→ 找到触发报毒的那一行/那一段
③ 只看那一段改写：拆成变量函数、引入中间变量让等号两侧不同、换等价写法
④ 重扫，直到引擎判定为"无后门"（而不是"已知后门变种"）
⑤ 功能回归：连一次、执行命令、上传下载都要复测
```

## PHPFuck 类字符集混淆

用 `(` `)` `[` `]` `!` `.` `^` `;` 等少量字符**构造任意字符串**（PHP 版 JSFuck），
特点是"文件里几乎没有字母数字"。代价：体积大、可读性为零、部分引擎按"字符集异常"报毒。
用法：只对**短载荷**用（如一句话的参数）、且与其它层叠加。

## 流量：按工具改

| 工具 | 默认特征 | 免杀动作 |
|------|----------|----------|
| 蚁剑 AntSword | UA 含 `antSword`、参数名固定（编码器 base64/rot13/chr）、PHP 里 `@ini_set('display_errors'…)` | **自写编码器**：改参数名 + 换加密算法 + 去 PHP 配置语句；改 UA |
| 哥斯拉 Godzilla | Cookie 值末尾带分号、首包明显偏大、响应体 16+32+16（md5 前后包裹 base64）、`getBasicsInfo` 明文回流 | 自写 java/php 加密器；改 Cookie/UA/Referer；短随机握手 |
| 冰蝎 Behinder | AES 密钥 = 连接密码 MD5 前 16 位、`Accept` 头固定、响应 `{"status":"success","msg":…}` | 改密码即换密钥；自定义协议/伪装正常业务接口；改响应结构 |
| 菜刀 Chopper | 旧 IE UA、`z0=`/`z1=` | 直接弃用 |

## 免杀验证（缺一不可）

```bash
# 静态：至少 2 个引擎 + 云查杀
# 流量：本地镜像/IDS 回放（pcap 重放）
# 动态：能落地的沙箱走一遍（360 全家桶/云沙箱会看行为，不只看静态）
```

失败也记录：哪个引擎、判定级别、命中位置（便于下一次直接绕过该点）。
