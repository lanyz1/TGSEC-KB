## Pitfalls
- Do NOT set `max-width` on `.content` — user complained "只占了一半多一点"; fill the canvas
- When patching a generic class, keep the generic selector: replacing `.thumb{…}` with `.prod .thumb{…}` silently broke every other `.thumb` (had to re-add the generic rule)
- Emoji placeholders (🖼🎥) read as slop; use neutral geometric placeholders
- AI-slop tells this user hates: glow/neon, gradients, grid lines, glassmorphism, oversized rounded rectangles, icon-topper cards, rainbow accents, feature-tile grids
- **Feature-bragging copy is banned** — "自动翻译 7 语 / 一键铺全球" style marketing text never goes into page copy (user: "后面的设计里面也不要带这种话"). Write only functional facts ("≤60 字", "多语言商品页即时生成" is the max allowed). Sweep whole file for the banned phrasing when fixing.
- After color approval, user iterates page-by-page: present a numbered page list with predicted per-page detail issues and let them pick the start
- Before asking "which direction", always offer visual variants — this user rejects on sight, so cheap iteration beats one big guess
- **SVG charts must re-render on window resize**: a fixed `viewBox` only scales proportionally — coordinates/labels don't reflow and hover math breaks ("缩放屏幕时趋势图不跟着动" was a user-reported bug). Keep `let curW` (init to viewBox width) + `window.addEventListener('resize', …)` that reads the container `clientWidth`, updates `viewBox`, and calls `drawChart(curN)` (remember current range in a global). Use `curW` everywhere inside the draw + hover handlers, not the old constant.
- **When the user says a direction is drifting ("越来越歪了") and offers to send a reference, STOP and wait — do not ship another variant.** The funds/payment-channel design was rejected 3× (RMB/alipay → USD-only wire → multi-currency bank accounts) before the user supplied the Stripe-style payment list; the reference text IS the spec (copy verbatim, preserve row order). Two rejections on the same module = ask for the reference instead of iterating blind. Also: in a cross-border-mall context, "支付通道/充值渠道" defaults to a payment-method selector (USDT/PayPal/Wise/cards/wallets), NOT bank-account management (Payoneer 收款账户/电汇) — do not design the latter unless the user explicitly asks for it.
- **Every new view must be registered in the `ROUTES` object**: `show(route)` silently falls back to `dashboard` for unregistered routes. The batch-ship page was added without a ROUTES entry and initially "worked" only because the DOM existed — it actually never displayed.
- **Verify view visibility with `classList.contains('active')`, NOT `style.display`**: `.view` visibility is driven by the CSS `.active` class (`display:none` default), so `style.display` reads `'none'` even for a visible page — a false-pass test. Same trap applies to checking modals (`.modal-mask.show`).
- **Hidden tabs measure 0×0**: `getBoundingClientRect()` returns all zeros for any element inside a `display:none` parent — you must ACTIVATE the tab (`setFundTab('recharge')`) before measuring widths/layout, or every number reads 0 (looks like broken layout when it's actually a hidden tab). Also remember the ledger strip is `view.children[0].children[2]` (a grid child), not `view.children[1]` — index against the grid container.
- **Stale browser DOM after patch**: after `patch`/`sed` edits, `browser_navigate` can serve a cached page; if a verified change (e.g. `grid-column:1/-1` in the file) is absent from the DOM, run `location.reload()` in browser_console and re-check before debugging the HTML.
- **patch() old_string must not be a shared base class**: replacing `.hint{…}` while intending to ADD `.title-tip{…}` silently deleted the `.hint` rule used by every other page — re-add the generic rule in the same patch
- **When replacing a JS function with patch, re-check neighbors**: one patch swapped `fakeShip` for the new `toggleTrace` (both one-liners near each other) and silently killed the batch-ship demo — grep the function name after editing
- **sed bulk-replace safety**: before `sed -i` on glyphs/short strings across a big HTML file, `grep -c` the target first to confirm it doesn't appear inside JS strings; after the run, grep again to confirm 0 leftovers. Verify rendered DOM via browser_console after any sed pass (a stale browser cache can show old content — `location.reload()` if snapshot looks stale)
