## Account settings (账号设置) patterns (verified 2026-08)
5-card 2×2+1 layout (`detail-grid` two columns): 个人信息 / 修改密码 / **店铺主体信息** / **通知偏好** / **关闭店铺**. Do NOT re-add a 安全设置 card (2FA/绑定手机/设备管理/登录历史) — user deleted it outright ("这个删掉吧").
- **店铺主体信息 = 入驻同步只读 + 审核制 (USER-MANDATED: "入驻通过之后自动与入驻信息同步,商家自己不能直接修改,修改需要提交审核,审核通过之后才能显示更新信息")**: all fields are `disabled` with `background:var(--gray-soft)` (主体类型/国家地区/注册证号/成立年份/经营地址/联系人/电话), top note bar `.deposit-note` ("主体信息与入驻资料自动同步,商家不可直接修改;变更需提交审核,审核通过后生效"), green 主体已认证 pill in the card header. Card footer = 提交变更审核 button (NOT a save button) + "审核周期 3-5 个工作日". Change modal (`modal-subject-change`): 变更类型 select (经营地址/主体名称/注册证号/联系人/联系电话) + 新内容 input + 变更原因 textarea + 附件材料 `.upload-dash` (dashed upload box with upload SVG + "上传营业执照/住址证明(图片或 PDF,≤10MB)") + orange risk hint (审核期间收款提现不受影响 / 可能触发风控复核). Submit → "已提交主体变更审核,预计 3-5 个工作日".
- **通知偏好 card**: 5 `.set-row`s each = bold name + `.hint` sub-line + `.tg` iOS-style toggle (`width:44px;height:26px;border-radius:999px;background:#E5E5EA`, `::after` 22px white knob translates `left:2px→20px`, `.on{background:var(--green)}`); `tg(el)` toggles `.on` unless `.disabled`. Categories: 订单通知 / 售后通知 / 资金变动通知 / 营销与活动 (default off) / 系统公告 (`.tg.on.disabled`, toast "系统公告不可关闭").
- **关闭店铺 card**: 关店条件检查 row (`st gray` pill "2 项未满足" + hint listing conditions) + 关店流程 row (提交申请 → 7 天公示期可撤销 → 资金结清 → 关闭店铺) → `modal-close-shop` risk modal: `.risk-box` red panel (商品立即下架/无法登录/资金结清后停止收款/保证金结清退还) + 关店原因 select + confirmation checkbox — **danger confirm button starts `.disabled` and only enables when the checkbox is checked** (`onchange="document.getElementById('closeBtn').classList.toggle('disabled',!this.checked)"`).
- Reusable bits: `.set-row` (dashed bottom border, flex space-between, 12px padding), `.risk-box` (`#FFF5F5` bg + `#FFD1D1` border + `#C92A2A` text, used by any destructive/risk surface), `.upload-dash` (dashed upload placeholder, shared with 主体变更/发布商品 attachments), `.tg` toggle.
