## Global notification bell + notifications center (verified 2026-08)
User asked for a topbar bell with a red unread dot (\"页面右上角加个通知按钮,有小红点那种\"), then for the full center page it links to. Three entry points stay in sync on unread counts.
- **Topbar bell** (`.actions` next to the language select, before 切换账号): `.bell-wrap` (relative) > `.bell` 36px round icon button (bell SVG, stroke `var(--ink)`) + `.bell-dot` absolute `top:-4px;right:-4px` red pill with count (white 2px border ring, `min-width:17px`, mono). Click → `.bell-panel` absolute dropdown (`top:calc(100%+10px);right:0;width:340px`, 14px radius, shadow, `z-index:100`) with `.bp-h` header (标题 + \"全部已读\" link), `.bp-item` rows (type SVG icon + `.bp-mid` bold title + muted detail line + `.bp-right` = `.bp-dot` red unread dot + `.bp-t` relative time), `.bp-foot` (\"查看全部通知\" → `show('notifications')`). `toggleBell(e)` stopPropagation; one document-level click handler closes it (same pattern as `.op-menu`/`.quick-panel`). `clearBell()` hides the bell dot AND the nav badge (linked below).
- **Notifications center page** (`view-notifications`, sidebar nav item in the 客户服务 group with `.badge` unread count, ROUTES entry REQUIRED): page-head (通知中心 + 全部已读 button) + `#ntTab` seg tabs 全部/订单/售后/资金/系统 + `.nt-list` of `.nt-item` rows: `.nt-ic` 38px tinted icon block (order `#E8F4FF`/`#007AFF`, aftersales `#FFF1E0`/`#FF9500`, fund `#E5F9EC`/`#34C759`, system `#F2F2F4`/`#6E6E73`) + `.nt-mid` (bold title, muted detail line carrying real business context: 单号 · 金额 · 时效, e.g. \"QX-… · 89.90 USDT,请在 48 小时内发货\" / \"剩余 4 小时将自动升级仲裁\") + `.nt-t` absolute datetime + `.nt-dot` unread red dot. Rows carry `data-nt` for tab filtering (`setNtTab` toggles display).
- **Three-way unread sync**: bell dot (id `bellDot`) == sidebar nav badge (id `ntNavBadge`) == page `.nt-dot`s. `clearBell()` (from the dropdown) and `clearAllNotif()` (from the page) BOTH hide all three — after one is marked read, the others must not stay lit. Keep demo data self-consistent: bell dropdown shows the same 3 unread items the page shows.
- Notification copy doubles as an ops cockpit: include 发货超时倒计时提醒 / 售后超时升级预警 / 资金入账 — these mirror real cross-page deadlines already in the prototype.
