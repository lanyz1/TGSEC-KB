## 3. 配套:路径关键词单字符编码

针对路径黑名单(如 `/druid`),把**关键词自身**的一个字符编码:

```
/druid/index.html   → 403 拦截页
/%64ruid/index.html → 302 ✓
/dru%69d/index.html → 302 ✓
```

规则通常按关键词字面量写,一个 `%XX` 就断开匹配,而后端仍会归一化并正常路由。

**实测无效**:编码别处字符、编码斜杠、双编码(`%252f`)、超长 UTF-8、`..;/`、`;` 矩阵参数、
双斜杠、尾点尾斜杠、`%00`。比"一个字符、在关键词内部"更花的写法对这家厂商基本是死的。

⚠ **不要从通用绕过表断言厂商绕过**。`401-403-bypass-techniques` 里"全编码/double-encode 都行"
那类行是通用矩阵,实测在本类云 WAF 上大量不成立。**扫矩阵、留命中的、丢掉其余**,
报告里只写实测命中的那几行。
