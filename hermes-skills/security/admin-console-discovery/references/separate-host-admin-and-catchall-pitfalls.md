# 管理端在「另一台机器」+ SPA catch-all 假阳性 + 出口过滤

本文件补充 `admin-console-discovery` 四步法之外的三类实战坑。全部结论来自实测(2026-09,一个白标博彩厂商家族)。

---

## 1. SPA catch-all 会让「200」变成假阳性(最贵的坑)

玩家前台是 SPA 兜底时,**任意路径都返回 200,且响应体字节数完全相同**:

```
/            → 200  6985 B   title dd66.com
/admin       → 200  6985 B
/admin/login → 200  6985 B
/login       → 200  6985 B
```

**拿 `/admin/login` → 200 当「后台存在」的证据是错的** —— 那只是兜底壳。

**判据:同一主机多路径的 body 长度/哈希一字不差 → catch-all,不能据此下任何结论。**
真后台会给出**不同的长度与标题**(如 title `Login - <Product> Admin`)。

**纪律:接手旧结论时,先把「X 路径 200」这类证据按本条证伪一遍再引用。**
本次就推翻了自己早前「demo01/02/03 的 `/admin/login` → 200 = 有后台」的结论 —— 实际全是 SPA 兜底,
后台根本不在这台主机上。**同一份笔记里被写下的 200,下一个人会当成事实。**

## 2. 管理端在另一台 IP 上,而那台可能正好被你的出口挡住

同族实测布局:

| 角色 | 主机 | IP | 备注 |
|---|---|---|---|
| 玩家前台 / demo 群 | `www`, `demo01~09`, `politico-demo` | 共享主机 A | 可达 |
| 控制面 | `ui-codex`, `xagents`, `gateway`, `webmail` | 共享主机 A | 可达 |
| **真管理端** | **`painel`**, `wpanel`, `cpanel`, `clonar`, `api-evo`, `api-bot`, `esquilo`, `pool` | **主机 B(另一 IP)** | **全部出口被过滤** |

**「管理端不在业务主域」是常态** —— 用四步法把子域**按 IP 分组**,
别默认后台是同主机的某个路径(本次 `/admin` 在主域只是 403,真后台整个在另一台)。

### 出口过滤的诊断姿势

某主机从跳板 `curl` 返回 **`000`**(python 则 ConnectTimeout),且:

1. **换遍手上全部跳板**(本次三台电信:深圳/内蒙/绍兴)
2. **扫全端口**(80/443/8080/8443/2082/2083/2086/2087/2095/2096)

**两者结果一样 → 是「出口被该主机过滤」(geo/IP 白名单),不是主机下线。**
此时**唯一出路是换非本地区出口**;继续在同出口换姿势/换端口是白费时间。

**反面判据:只有一台跳板不通 → 先比较各跳板出口再下结论**(可能那台机器坏了,而非目标过滤)。

## 3. 跳板 DNS 解不了目标域时的工作流

国内跳板的 DNS 常解不了新域名/境外域(`socket.gethostbyname` 抛异常,curl 直接失败)。
**别因此放弃目标**,标准三步:

```bash
# 1. 本机走代理查公共 DoH
curl -s --proxy socks5h://127.0.0.1:10808 \
  "https://dns.google/resolve?name=<host>&type=A"
# → 45.13.59.23

# 2. 把解析结果写进跳板 /etc/hosts
echo '45.13.59.23  <host>' >> /etc/hosts

# 3. 跳板上直连该 IP + Host 头(顺带绕过 CF 挑战页)
```

**批量 DoH 查一段子域名单是廉价且高产的**(本次一次捞回 `painel`/`wpanel`/`xpanel`/`gateway`/`clonar`/`x-agents` 等的 IP)。
注意区分「**无 A 记录**」与「有记录但连不通」—— 前者是域名没部署(如商品页里写的开发者 demo 域),
后者才值得换出口继续打。

## 4. 本族「panel」命名字典(实测命中率高,可直接并入字典)

```
painel       葡语「面板」= 主管理端(本轮命中,含 wpanel/xpanel/cpanel 三兄弟同 IP)
wpanel       panel 变体
xpanel       与「X-Agents」产品同名 —— 面板产品名常直接出现在子域里
cpanel
clonar       「克隆」= 一键克隆白标站的服务 ★ 值得单独打(克隆服务往往能列出全部租户)
gateway      ★ 与玩家站同机、同 Apache 加固(/admin/ /api/ /actuator/ 全 403)
api-evo / api-bot / esquilo / pool / dm / html5 / teste
```

**`gateway` 值得当独立目标**:本次它本身就是一台**活赌场站**,和主目标同族但可能是**另一台生产实例**,
其 `/admin/`、`/api/` 被 Apache `Require all denied` 挡(与主站同款配置)→ 按同款套路重走一遍路由 oracle。

**`clonar` 优先级高**:字号「克隆站」的服务通常有租户/站点列表接口,是**一次看全同族资产**的捷径。
