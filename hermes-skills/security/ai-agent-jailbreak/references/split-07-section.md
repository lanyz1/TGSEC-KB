## 六、完整执行流程

```
┌─ 目标选定 ───────────────────────────┐
│  确定目标模型和预期输出                │
└─────────────────┬────────────────────┘
                  ↓
┌─ 通道选择 ───────────────────────────┐
│  选安全策略最宽松的通道                │
│  优先级: AWSQ直连 > Codex > Workflow  │
│  每个通道独立 Session，互不影响        │
└─────────────────┬────────────────────┘
                  ↓
┌─ 第一阶段: 情报搜集 ────────────────┐
│  • 目标指纹识别 (WAF? 框架? 语言?)   │
│  • 目录/端点枚举                     │
│  • 关联域名发现                      │
│  • Session/Cookie 审计              │
└─────────────────┬────────────────────┘
                  ↓
┌─ 第二阶段: 模型调用 ────────────────┐
│  AWSQ 直连 (首试, 成功率最高)         │
│  使用 CTF 框架 + 脱敏词              │
│  每轮产出立即保存到本地文件            │
└─────────────────┬────────────────────┘
                  ↓
┌─ 拒绝应对 (按优先级) ──────────────┐
│  1. 移出域名重新问 (域名识别拒绝)     │
│  2. Pack Hunt 分解 (语义识别拒绝)     │
│  3. 重启新会话 (上下文疲劳)           │
│  4. 降级目标模型 (Claude→Codex)      │
│  5. 多模型并行 (同时问不同模型)        │
└─────────────────┬────────────────────┘
                  ↓
┌─ 第三阶段: 手动组装 ────────────────┐
│  • 取各零件输出拼装完整工具            │
│  • 针对 WAF 调整 payload             │
│  • 多轮反复测试                       │
└─────────────────┬────────────────────┘
                  ↓
┌─ 成果固化 ──────────────────────────┐
│  输出立即保存到文件                   │
│  手动组装最终 exploit                │
│  打包为成果包                        │
└─────────────────────────────────────┘
```
