# 四层记忆系统工作流（越挖越强）

> 挖洞是信息战：观察即记、线索即存、判断即融、手法即图谱。四层记忆让每一个目标都变成下一个目标的弹药。

## 四层结构

| 层 | 特点 | 记什么 | 存哪 |
|----|------|--------|------|
| 瞬时层 | 每条观察即记 | 接口、参数、回包特征、状态码、header | 任务笔记 `任务名/notes.md`（随时追加） |
| 工作层 | 高价值线索/半成品结论 | 可疑点、待验证假设、资源 ID、差分基线 | 任务笔记中标记 ⚑ 高亮，或单独 `任务名/leads.md` |
| 短时层 | 融合后的技术判断 | 该目标哪个模块什么玩法、验证结果 | 任务笔记结尾小节「技术判断」 |
| 长时图谱 | 跨目标可召回 | 「手法 → 目标特征 → 成果」三元组 | 个人记忆（memory_write 到 daily log / 个人手法库 `手法库.md`） |

## 写入时机（即时性要求）

- **瞬时**：每打一个新接口、每次回包有异常，30 秒内记下关键字段
- **工作层**：发现可疑差分（total 变化、他人字段、异常响应）立即标 ⚑
- **短时层**：一类测试收尾时（如「订单模块越权面已穷尽」）落一段判断
- **长时**：一次任务结束后、或发现可复用新手法时，蒸馏成三元组

## 长时图谱蒸馏规则

三元组格式：`[手法] | [目标特征] → [成果]`

示例：
```
[换 id 越权] | 详情接口带数字 id 且不校验归属 | → 读他人收货地址（高危）
[未登录发签口] | 回包 nonce 以 MIIE 开头 | → RSA 私钥泄露 → 伪造任意用户票
[STS 通配覆盖] | 对象存储 key 是文件 md5 | → 覆盖他人文档（高危）
```

要求：
1. **手法要可复用**：写清楚触发条件（什么特征→试什么）
2. **目标特征要具体**：不是「有列表就换 id」，而是「列表按 tenantId 过滤 + 附件带 sign URL」
3. **成果要如实**：写实际拿到的（不是理论可能）

## 每轮结束自检（三问）

1. **什么手法有效**？—— 这次挖洞中哪种打法出成果了（换 id？发签口？JS 钥匙？）
2. **什么目标特征对应什么漏洞**？—— 提炼新的特征→漏洞映射，进长时图谱
3. **下次先打哪**？—— 基于本次经验给下个目标排序优先级

## 与平台记忆系统配合

- **memory_write**：任务结束后把「目标+手法+成果」三元组写入 daily log（跨会话可召回）
- **任务目录**：`任务名/笔记.md` 保留原始证据与详细过程（长时图谱只存蒸馏结论）
- **复盘**：每周/每目标做一次长时图谱回看，删除无效三元组，合并重复手法

## 红线
- 记忆里**不存**会话密钥/明文密码/完整 token（证据放任务目录并注意保密）
- 长时图谱存「手法 → 特征 → 成果」，不存具体受害者数据
