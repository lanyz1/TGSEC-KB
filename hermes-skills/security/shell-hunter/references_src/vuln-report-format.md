# 漏洞报告格式守门（vuln-report-format）

> **写不写、怎么定级，只认本文件**（思念技能内以 `report-format.md` 为完整版，本文件是引用别名 + 硬守门）。

## 硬规则
1. 中危/高危/严重确认后**立即落盘** `报告/xxx.md`，禁止攒到最后
2. 报告 8 块结构：标题 / 目标URL / 等级 / 描述 / 危害 / 涉及接口 / 复现步骤（可整包复核）/ 修复建议
3. 定级标准（摘要）：
   - **严重**：命令执行、进他人号、改密/改绑、真实资损
   - **高危**：对得上人的高敏数据、云密钥/token/连接串（过认钥闸）、注入出他主体、他人未公开正文
   - **中危**：存储 XSS、非资损逻辑越权、低敏越权读、SSRF 无实质危害
   - **低危**：反射 XSS、配置类、纯信息泄露
4. **认钥闸**：抄到钥不算洞。假值对照 + 认钥带出身份/列表，两条都过才写高危
5. CORS 单独报告一律不写（见 `cors-vuln-report-priority.md`）
6. 差分即证据：越权/注入类附基线 vs payload 差分，状态码 200 不是漏洞
