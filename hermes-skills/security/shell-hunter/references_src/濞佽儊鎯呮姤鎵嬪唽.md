## 二、TTP 聚类：国家级能力常见的共性特征

1. **双栖开发**：Mac+Windows 双版本样本（跨平台目标）
2. **供应链优先**：先打软件更新/依赖/第三方（隐蔽持久）
3. **凭证优先**：不弹 RCE 直接偷凭证（登录合法比攻破便宜）
4. **C2 隐蔽化**：合法服务中继（云存储/CDN/社交平台）+ 加密流量 + 域前置
5. **持久化纵深**：多重驻留（计划任务+服务+注册表+内存），失联自动重建
6. **反取证**：内存执行、加密+自毁、时间线清理
7. **低频慢速**：控制节奏模拟正常行为（避行为基线检测）

## 三、情报研判流程（分析一个 IOC/样本）

```
收集 → 关联（同类样本/同 C2/同域名注册模式）
  → 上下文（时间窗、目标行业、攻击手法组合）
  → 置信度评估（单一证据 vs 多重独立证据）
  → 输出（TTP 卡片 + 检测规则 + 处置建议）
```

输出模板（TTP 卡片）：
```
TTP: T1071.001 应用层协议 C2 (HTTPS)
样本/链路证据: SHA256/域名/IP/证书指纹
关联: 与公开报告 XX 组织的 C2 基础设施重叠（域名语法/注册邮箱）
置信度: 中（基础设施关联 2 条 + TTP 相似 1 条；缺样本归属证据）
检测: Sigma 规则 XXX / EDR 行为 XXX
```

## 四、从情报生成检测（情报→规则流水线）

1. 公开报告 → 提取 TTP + IOC（域名/IP/哈希）
2. IOC 过期快（24h），**TTP 是长效资产**（多久都有效）
3. 规则化：TTP → Sigma/YARA/EDR 行为（见 `威胁狩猎与检测工程.md`）
4. 覆盖验证：原子模拟测试自家检测（见检测工程手册）
