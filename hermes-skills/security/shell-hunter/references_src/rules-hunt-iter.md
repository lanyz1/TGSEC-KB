# hunt-iter.md（思念迭代规则层）

> 思念技能的知识库持续迭代基座。本文件是**唯一的增量写入口**：进站/补短表/新增经验只认本文件现稿，禁止用会话旧副本覆盖。只增强、不限制。

## 迭代协议
1. **每次实战后**：检查 `知识库/打野短表.md` 是否覆盖本次有效手法。没覆盖 → 按格式追加一行（认什么 | 打哪 | 出什么算成 | 假点）
2. **新手法入库条件**：已在真实目标验证有效（出过真实差分/数据），或来自可信外部情报（0day 通告/公开分析）。理论猜测不入表
3. **假点必填**：每行必须有「假点」列（什么情况下这个手法不成立），防止下次误判
4. **先读后改**：改任何知识库文件前先 file_read 现稿，禁止凭记忆覆盖
5. **冲突裁决**：本文件与 `memory-system.md` 冲突时，本文件管「知识库写入」，memory-system 管「会话记忆」，互不覆盖

## 红线再确认（写入任何知识库不得违反）
1. 授权红线：非授权目标禁测
2. 最小伤害：读差分优先，写必须可控可回滚
