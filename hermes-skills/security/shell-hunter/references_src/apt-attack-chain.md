# APT 攻击链 + MITRE ATT&CK 攻防视角

> 用途：① 对目标/红队演练环境输出攻防双视角分析；② 帮助红队规划攻击链与蓝队建立检测规则。攻击视角按 MITRE ATT&CK 编号标注 TTP，防守视角给每条 TTP 检测规则与缓解措施。

## 二、防守视角（检测规则 + 缓解措施）

### 检测规则速查（日志/EDR/流量三层）
| 战术 | 日志特征 | EDR 事件 | 流量特征 |
|------|---------|---------|---------|
| 初始访问 | 登录失败激增、陌生源 IP、老漏洞路径 404→200 | 漏洞利用告警、钓鱼附件落地 | 异常协议端口、可疑 TLS 指纹 |
| 执行 | 创建进程链：office→cmd→powershell | 子进程异常（父进程非预期） | 请求体带 base64 大段 |
| 持久化 | 注册表 Run 新增、计划任务新增、启动目录新文件 | 新服务注册、新增账户 | WebShell 周期性请求 |
| 提权 | 令牌操作日志 4672/4688、服务改动 | 权限提升告警 | — |
| 规避 | 大量进程注入、防御进程被终止 | 禁用了 EDR 服务告警 | 加密流量特征（冰蝎/哥斯拉） |
| 凭据 | lsass 访问异常（mimikatz 特征） | 内存抓取告警 | — |
| 发现 | 大量 net/arp 查询、AD 枚举查询 | 批量枚举告警 | 内网端口扫描流 |
| 横向 | 异常 SMB/SSH 登录、共享访问 | 哈希传递告警 | 内网横向连接突增 |
| 外渗 | 大流量上传、DNS TXT 异常多 | 压缩+上传行为链 | DNS 隧道特征、深夜大流量 |
| C2 | 长连接、心跳、域历史与证书不符 | 可疑外联告警 | JA3/JA3S 指纹异常 |

### 缓解措施框架
1. **缩小攻击面**：公网服务收敛、VPN MFA 强制、漏洞及时修补
2. **纵深防御**：分段网络、最小权限（含服务账户）、应用白名单
3. **检测先行**：端点 EDR + 流量检测 + 日志集中（SIEM），告警规则按上表落地
4. **响应预案**：隔离→取证→根除→恢复→复盘；演练「检测 → 响应」闭环
5. **防外渗**：DLP、出网管控（只放行必要域）、DNS 日志监测隧道

## 三、红队演练交付格式

```
[攻击链]
1. T1190 → 打 XX 系统老 CVE → 落 WebShell(T1505.003)
2. T1078 → 撞库进入员工账户 → 钓鱼(T1566) → 客户端执行(T1203)
3. 提权(T1068 内核洞) → 凭据转储(T1003) → 横向(T1021 SMB)
4. 收集(T1114 邮箱) → DNS 隧道外渗(T1041/T1573)

[检测缺口]（对应上面每条该被发现而没被发现的点）
[修复优先级] P0/P1/P2 + 责任方
```

## 四、红线提醒
- APT 攻防分析允许对**授权演练环境**做全链；对真实目标只做**防守侧评估**或配合蓝队检测复盘
- 不得对真实生产系统使用本链条做未授权攻击模拟
- 攻防分析输出的全是「TTP 编号 + 检测规则 + 缓解建议」，不是攻击步骤教程
