## Key Findings

### Login Process
- Site requires registration with Geetest CAPTCHA v3
- API: `POST /tools/_ajax/login` → body `{"Action":"login","Requirement":{"username":"...","password":"..."}}`
- Login returns JWT token in response header `token`
- JWT stored in `localStorage.getItem('token')`
- Login may return 403 from Python environment but works from browser (same-origin)

### API Architecture
- All API calls: `POST /tools/_ajax/{Action}` with JSON body `{"Action":"...","Requirement":{...}}`
- Response format: `{"code":"success|fail|nologin|error","data":...,"msg":"..."}`
- No CSRF token required (credentials: 'same-origin' suffices)
- Game config: `isSelfGame: true` — custom/self-owned lottery → results pre-generated by admin

### Lottery Results — Extracted from Vue Pinia Store

The lottery results are NOT accessible via the direct API (returns "服务器内部错误" for SG31K3). Instead, the data is already loaded into the Vue.js Pinia store by the page:

```javascript
// Access via CDP Runtime.evaluate:
var pinia = document.querySelector('#app').__vue_app__.config.globalProperties.$pinia;
var results = pinia.state.value.lottery.LotteryResults.SG31K3;

// Structure:
{
  time: "2026-07-20T18:43:33.653Z",
  results: [{
    gameId: "SG31K3",
    gameName: "一分快3-3",
    issueNo: "20260721163",       // Period number
    lotteryOpen: "3,3,4",         // Lottery code (comma-separated)
    awardStatus: null,
    resultDate: "1784572983396",  // Unix timestamp
    openTime: "02:43:03",         // Open time
    count: 10,                    // Sum of numbers
    daxiao: "xiao",               // 大/小 (da/xiao)
    danshuang: "shuang"           // 单/双 (dan/shuang)
  }, ...]
}
```

**Up to 200 periods of history available** directly from the store.

### Post-Login State (localStorage keys)

Key localStorage entries after login:
- `token` — JWT authentication token
- `user.loginName` — username
- `user.Balance` — balance (JSON)
- `user.accountId` — numeric account ID
- `user.type` — user type (0=regular)
- `user.parentId` — agent/admin who invited this account
- `site.lotteryList` — all game configurations (keyed by game code)
- `__uuid` — browser UUID
- `abcdefg` — login persistence config (JSON)

## Authentication Flow
1. User registers via browser (Geetest CAPTCHA required)
2. POST `/tools/_ajax/login` → returns JWT in `token` header
3. Subsequent API calls use `authorization` header with JWT value
4. Session managed server-side; `credentials: 'same-origin'` for API calls
