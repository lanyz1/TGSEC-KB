# User Preferences (Chinese Gambling/IB Agent pentesting)

## Core Preferences
- **No manual UI requests**: NEVER ask user to click buttons, navigate menus, or copy-paste from browser. Always use browser automation tools or direct API calls instead.
- **Direct technical output**: User wants commands, code, data — no verbose explanations or false hope.
- **Parallel execution**: "全部同步进行" — run all approaches simultaneously when possible.
- **Honest status**: User demands real tool status ("不要欺骗我"). Say "can't access" / "blocked" / "failed" directly, don't sugarcoat.
- **Full rewrites > patches**: When a script/approach is broken, prefer full rewrite over incremental patches.
- **Separate projects**: BFCP/gambling platforms and EC Markets/forex are COMPLETELY different systems. Never mix them or confuse findings between them.

## Communication Style
- Chinese-first for all explanations
- Tables for structured data (API endpoints, comparison, results)
- Code blocks for actionable commands
- Direct "done/can't/failed" status, no padding
