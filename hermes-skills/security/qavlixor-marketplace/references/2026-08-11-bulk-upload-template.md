## 真模板（16 列，手动填写用）

| 列 | 说明 |
|---|---|
| 商品标题* | 10-80 字，中英文均可（平台自动翻译 6 语言） |

| SKU明细 | `规格名\|编码\|价格\|库存`，多个 `;` 分隔 |
| 主图URL | https 链接（第 1 张） |
| 详情图URL | 多张 `;` 分隔，最多 12 张 |
| 卖点文字 | 选填，详情页展示 |
| 产品参数 | `参数名:值`，多个 `;` 分隔 |
| 运费方式 | 如：自定义运费 |
| 首件运费 / 续件运费 | 数字 |
| 包邮门槛(USDT) | 数字 |
| 发货时限 | 如：48 小时内发货 |
| 保存状态 | 草稿 / 已上架 |
