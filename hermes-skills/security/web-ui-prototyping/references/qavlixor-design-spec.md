# Qavlixor 卖家端 · 设计规范(Apple A2 · 已定稿)

> 这是给用户/任何 AI 的完整提示词,设计迭代时贴在需求前面。SKILL.md 只含摘要,此文件为全量色值与组件规范。

## 项目背景
- 跨境电商卖家后台(类 Shopify / TikTok Shop 卖家中心 / Temu 卖家后台)
- 金额单位 USDT(不做多币种);PC Web 为主,需响应式
- 页面:工作台 / 商品管理(列表、发布)/ 订单(列表、详情、物流)/ 售后(列表、详情)/ 买家消息(三栏)/ 资金中心 / 账号设置 / 登录注册 / 入驻 4 步 / 审核状态

## 硬性禁令
1. 禁产品吹嘘文案:"自动翻译 7 语""一键铺全球""智能生成" 类话术一律不用,只写功能事实("≤60 字")
2. 禁 AI 味:渐变 / 发光 / 霓虹 / 网格线背景 / 毛玻璃滥用 / emoji 图标(用 SVG 线条图标)
3. KPI 卡无彩色圆点装饰;趋势色用 Apple 绿/红
4. 图表克制:黑线 + 极淡渐变面积,网格极淡,标签稀疏

## 文案与数据规范
- 日期:页面标题下 `2026年7月31日`;表格内 `07-31 09:12`
- 金额:等宽数字字体,单位 USDT;演示数据必须自洽(客单价 = 销售额 ÷ 订单数)
- 空态友好:说明原因 + 下一步动作

## 工作方式
1. 先出完整页面样图(或关键区域)标改动点,再动手
2. 一次只调一个页面/模块
3. 交互必须可用(点击有反馈、筛选真过滤、排序真排序),不做死图
