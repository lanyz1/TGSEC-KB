# 资产族扩线 + 新面服务初筛

手里只有一个具名域或一个已知 IP，要**把同族资产一次扩出来**，并对新面做**零副作用**的可达性与脆弱服务初筛。
本技能只管「扩线与初筛」这一步；引擎语法/额度坑见本库的空间测绘类技能（用户自有，勿改）。

## 何时用

- 单目标打不动，需要**横向找同族更松的站**
- 已经有一个 IP（源站/后台/跳板），想知道「这台机器上还挂着什么」
- 要写批量探测脚本，先要一张「值得打的资产清单」

## 铁律

1. **引擎可用性先验，再写批量脚本。** 用一条最便宜的查询确认凭据真能用（额度/实名/欠费都可能让 key 直接不可用）；
   不可用就换引擎重跑。**不要把引擎凭据散在仓里乱搜** —— 本机常有一份集中配置（含各引擎 key/登录邮箱），直接读它。
   大目录全文 `grep -r` 在 Windows 上极易超时（exit 124）⇒ 用定向搜索或直接读已知路径的配置文件。
2. **两个反查方向都要做**：`domain=<已知域>` 拿域族资产；`ip=<已知IP>` 拿该 IP 的**全部域名 + 端口 + 服务 + 标题**。
   这条比端口扫描优先：全程第三方数据、不碰目标、无日志。
3. **同 IP 多域 = 白标站群 = 横向面。** 同一源站上常挂着同构站群（`int.<品牌><NN>` 命名族）+
   若干浅层静态域；**契约/后端常共用而各站配置松紧不一** ⇒ 一台的指纹/签名/风控闸打不动时，
   拿同一份请求契约横向打同族另一台，比继续磨当前站便宜一个量级。扩族时留意**静态站在另一个短域**上。
4. **新面一律走跳板/代理出口**（`socks5h://127.0.0.1:<port>`），不走本机真实出口。
5. **集体超时 ≠ 服务未开。** 先找会回显对端 IP 的协议自证（见下面判读表），再决定是「换出口复测」还是「登记为目标无此服务」。
6. **归属先核实再开打。** 仅凭同 IP 或标题相似**不足以**认定与已知目标同主体（配置里的域名/同 C 段常是历史残留或第三方停放）。
   先做被动核对（WHOIS / 证书 / 页面文案 / 备案）再动手。

## 流程

1. 读本机引擎配置 → 一条探针验引擎可用性 → 选可用引擎。
2. `domain=<目标域>` 扩域族：挑出**后台/管理/测试/新品牌**类域名（标题与域名双筛）。
3. 对已知 IP（源站/后台）做 `ip=` 反查：按 IP 归并出 `IP | 域名 | 端口 | 服务/标题`。
4. 对新面 IP 做**读一类**的服务初筛（顺序：Redis → MySQL → FTP → WinRM/SSH 只记存在）：
   - `6379` Redis 未授权 `PING`/`INFO`（一旦通 ⇒ 写 `authorized_keys`/计划任务即 shell）
   - `3306` MySQL 握手 + 极少默认口令（`root` 空、`root/root`、`root/123456`）
   - `21` FTP banner + 匿名
   - 见 `references/ip-reverse-expansion.md` 的判读表（超时 vs RST vs 真 banner vs 真握手）
5. 判读方向：**能握手但口令错 = 面真存在**，只差凭据；**集体超时 = 出口路径问题** ⇒ 换出口复测，别写成「服务已关闭」。
6. 落盘：`fofa_assets.json`（原始条目） + 归并表（`IP | 域名 | 端口 | 服务/标题 | 判读`），
   新面按价值排序：**托管支付/账务 > 多站后台登录面板群 > Windows+WinRM（等凭据）**。

## 第三方向：品牌/供应关系反查上游主体

`domain=` / `ip=` 只能扩「同一主体名下」的资产。当主站加固、同 IP 也没有软面时，换一个轴：**目标的供货方**（上游号源/短信/支付/卡商/AI）。
它往往不是同一主体，而是**另一家公司、另一段 IP、配置差一个量级**，而且常常握着目标业务的“货”本身。

入口不是域名而是**品牌名**：
1. **让应用自己点名上游**：故意带错参数/不存在的 ID 调依赖上游的业务端点，读透传的上游错误体
   （`<上游名>接口请求失败：{"detail":"product not found"}`；`{"detail":...}` ⇒ 上游是 FastAPI）；
   前端 bundle 的集成字段（`settings.<vendor>_api_key`）与客服话术同样点名。
2. **品牌当测绘关键词**：`body="<品牌中文名>"` / `cert=` / `title=` ⇒ 常一发命中上游**公开 API 文档站**与同族**运维后台**。
3. **上游文档 = 免费契约**：`/openapi.json`、`/docs`、`/swagger-ui/index.html` ⇒ 拿鉴权头名/签名要素/端点全集
   与**开通方式**（写“人工开通”即无自助注册 ⇒ 别再找注册面，转去找持有 key 的那一方）。
4. **从面板前端反挖同族域**：面板 SPA HTML 常免鉴权（如 `/admin/dashboard`）⇒ grep `API_BASE`/`http(s)://`/
   `localStorage`/集成字段，一次拿到同族子域（取号站、Basic 门户、分销 API）+ 鉴权机制。

纪律：**归属先核实**（铁律 6 同样适用：页面互引/同一运营方/同一号源）再动手；
**没 key 就别原地磨签名**（分层错误文案只配当格式/账号 oracle）；价值排序 =
**能导出/接管账号实物（session/tdata/发货文件）> 能下单/看余额 > 只能看货架**。
配方与实测见 `references/brand-pivot-upstream-supplier.md`。
