- **环境隔离**：测试在专用设备/隔离网络进行；生产环境未经批准禁止动态利用
- **痕迹清理**：测试完成后删除写入的文件、Hook 脚本、代理证书、重签名包
- **合规红线**：不绕过付费墙/DRM 盗版、不制作分发恶意软件、不用于间谍软件（如商业监控）用途
