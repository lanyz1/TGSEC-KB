# 95306 Bot v7.16-v7.19 会话增量经验

## 分页索引偏移 bug(用户实测抓出,经典)

- 症状:第 2 页点"5"打开的是第 1 页第 5 个项目(全局索引=页内序号)
- 根因:`list_open(cid, idx)` 用 `items[idx]` 取全局,但数字按钮传的是页内序号(1-5)
- 修复:按钮 callback 带页码 `listopen:{page}:{i-1}`;`list_open(cid, page, idx)` 内 `real = page * st["per"] + idx` 再取 `items[real]`;`handle_text` 数字回复同样带 `st["page"]`(LIST_STATE 需存 page/per)
- 教训:凡"页内序号→全局列表"映射必须做偏移;模拟验证用 `list_open(cid, page=1, idx=4)` 期望 items[9]

## TG 按钮宽度实测(用户反复调,最终结论)

- 全角空格填充无效:TG 渲染裁剪/忽略按钮尾部空格,wide_center 撑宽不生效
- 真实文本长度决定按钮宽度:加描述文字(如"数据池(实时项目)")才有效
- 但手机一行两按钮 18 字符会截断显示不全 → 最终回退 5-6 字符短文本
- 结论:手机两列按钮文本 ≤6 字最安全;"宽"与"显示全"不可兼得,优先显示全

## 部署 daemon 路径核实(严重事故)

- merge_daemon.sh 写死 `python3 /opt/v6/merger.py`,上传新版到 `/opt/v6/t95306_v6_merger.py` 从未生效 → 修复轮全部白做
- 部署后验证链:`cat merge_daemon.sh`(看实际文件)→ `ps aux | grep [m]erger`(确认进程)→ `grep -c 新标志 /opt/v6/<实际文件>`(确认代码在位)
- 覆盖到 daemon 实际路径后必须:杀全部相关进程(`pkill -9 -f 'merger.py'` + `pkill -9 -f '[m]erge_daemon'`)→ 重启 → 等一轮 → 验证新输出文件出现
