## 三层 SSH 文件传输模式(本机→主服→采集机)

多层 SSH + heredoc 嵌套**静默失败**(exit 0 但无输出,PYEOF 冲突)。可靠模式:
1. 本机写内层脚本 r_xxx.py(采集机执行的内容)
2. 本机连主服:sftp.put 传 r_xxx.py 到主服 /tmp
3. 主服连采集机:sftp.put 再传 + exec python3 /tmp/r_xxx.py(每层都传文件,不嵌 heredoc)
- 常见坑:`import time` 缺失(三层脚本各层都要 import,两次踩过)
- 验证输出用 `out.channel.recv()` 循环读,勿只 read()(会阻塞到超时)
