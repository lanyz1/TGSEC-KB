## 1. API 传参动态配置(进阶包网接入)

大型综合包网平台通过游戏厂商 API 做高级控制:

```
玩家发起游戏 → 包网平台调游戏厂商 API(Create Session / Launch Game)
     ↓
API 请求参数携带 rtp_level 或 config_id
     ↓
平台按玩家画像动态指定 RTP(返还率)
```

**风控场景**:识别到该玩家属于"高风险/刷子账号"(赢太多/异常下注/多开/脚本),系统调用 API 拉起游戏时,自动传参指定**最低档 RTP** → 压低刷子胜率,平台止损。

**本质**:普通玩家给正常 RTP(留住用户),刷子给最低 RTP(反制)。双轨风控——"玩家看到的公平"和"平台实际控制的概率"是两套系统。

## 2. RTP 概念

- RTP = Return To Player,玩家返还率
- RTP 95% = 玩家每投注 100 元,长期平均拿回 95 元
- 平台留存 = 100% - RTP
- RTP 越低,平台赚越多,玩家输越多

## 3. 配置后台截图解读(实拍)

包网平台「各游戏接口 RTP 配置」页面:

**顶部风险等级说明:**
| RTP 区间 | 含义 |
|---|---|
| 70%—79% | 高风险区间,大奖概率极低 |
| 50%—69% | 极度波动,多数情况输钱 |
| <50% | 几乎无返奖,玩家体验极差 |

**配置表(接口 ↔ RTP 值):**
| 接口 | 配置值 | 状态 |
|---|---|---|
| PGS | 0 | 可编辑输入框 |
| FCS | 0 | 可编辑输入框 |
| PPS | 0 | 可编辑输入框 |
| CQ9S | 0 | 可编辑输入框 |
| JDBS | 1(正常官网) | 文本 |
| JILIS | 2(平衡慢杀) | 文本 |
| WGS | 3(快杀) | 蓝色强调 |
| AGS | 3(快杀) | 下拉框(聚焦) |

**档位体系**:0(关闭/未配置) → 1(正常官网) → 2(平衡慢杀) → 3(快杀,返还率最低,平台留存最高)。

**厂商缩写**:PGS=PG Soft、CQ9、JDB、JILI、W(G) Game、AG(亚游)等 —— 包网聚合的典型老虎机/捕鱼厂商列表。
