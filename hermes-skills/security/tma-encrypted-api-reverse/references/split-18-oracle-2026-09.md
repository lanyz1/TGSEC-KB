## ★★★ 路由 oracle 的「时变性」：多副本/灰度 + 探针自证（2026-09 增补，推翻单次观测）

- ★★★ **同一 `(路径+方法)` 在不同时间窗口会给出互斥结果（`401`=存在 / `404/18B`=不存在）** ⇒ 服务端存在**分段行为窗**（Mode-A：路由可达 / Mode-B：一律 `404`），不是「路由不存在」。**已定论（并排除"按请求随机落副本"）**：全量枚举 **1040 发**（227 名 × 2 命名空间 × 2 方法 + 132 发二次采样）中，4 条真路由**各恰好命中 2 次**、1032 发清一色 `404` 且**零交替**，头/尾 CTL 块（相隔 10 分钟）逐字节相同 ⇒ 切换以**整段区间**为单位，窗内完全确定。实测同一站：`09:0x` 窗口 `GET rp/detail`→`401`；`09:1x` 同请求**十连发全 `404/18B`**；`09:2x`→`400` 业务层；`09:34` CTL 又全 `401`；甚至**同一轮脚本内**（14 发无票 `401` 之后、162 发带票全 `404`）⇒ **翻转粒度在秒~十秒级**。
  ⇒ **判定纪律**：① 每发**带时间戳落 JSONL**（否则整轮 0 命中分不清「无路由」与「整轮落在坏窗口」）；② **同发重复采样 ≥3 次**；③ 扫描脚本**头尾各放 CTL 块自诊断当次窗口**（已知端点打两方法），CTL 显示坏窗口时该轮结果**整批标注不可用**；④ 负结论只能表述为「**在该窗口内 404**」，不得写成「不存在」。
- ★★★ **「缺参数 ⇒ 服务端伪装 404」是我自造的假机制，已在同窗口内被证伪**：`GET rp/detail` 裸路径 → `401`、`GET rp/detail?token=<假>` → `401`（**同一分钟内背靠背**，结果相同）。先前「裸 404 / 带 query 400」实为**跨窗口采样造成的伪相关**（那两条读数分处不同窗口）。⇒ 铁律：**任何「某参数/某 header 决定路由匹配」的结论，必须同一窗口内做 A/B 对照**，跨时段拼出来的相关性一律无效。
- ★★ **探针 helper 必须显式传方法**：自写 inline helper 若忽略传入的 method（一律按 POST 发），会把「GET 未注册」误读成「GET 已注册」。实测 `rp/verify-segment` **只注册 POST**（`GET`→`404/18B`、`POST`→`401/63B/40701`），而 helper 曾把它报成 `GET→401`。⇒ **自检配方：同一路径的 GET 与 POST 必须在同一分钟内背靠背各打一次**（CTL 块同时给两方法），并对已知方法的路由做正控。
- ★★★ **全量枚举的验收标准（四项全中才能写「路由穷尽」）**：① 头/中/尾**三个 CTL 块**逐字节同模式；② **两个不同出口**（本地 + 跳板机）各跑一轮**同一词表**；③ 两轮的**总发数相同**（词表/方法/命名空间组合必须对称）；④ 两轮的**命中集与每条命中次数完全相同**（实测：1040=1040、同 4 条各×2、全 Mode-A）。任一项不符 ⇒ 只能写「**在该窗口内**未发现」，**禁止**写「路由不存在」。异地执行优先 `requests` 长连接 + `setsid nohup … --bg` 自守护（curl 子进程本机约 2–4 s/发，1040 发要约 66 分钟；bj + requests 约 0.6 s/发，同样 1040 发 10 分钟）。
- ★★ **`404` 有分层，别混为一谈**：`404/18B/53af239e`（Go/Gin 原生 `404 page not found`）= **应用路由层未注册**；**`404` 且 `b=0`**（实测 `GET /media/bg` 无票）= **外层（nginx/代理/S3/未代理）拒绝**，连应用都没到 ⇒ **0B 的 404 绝不能记「路由不存在」**。分组统计时按 `b` 与 md5 把两族分开。
- ★★ **异常码本身就是可判据资产**：本轮实测阶梯 `40701`(无凭据/401) · `40703`(签名不符/401/45B) · `40704`(initData 已消费/400) · `40705`(会话已失效/400) · `40710`(假 `X-Session-Id`/400) ⇒ 出现在哪一阶就说明鉴权链走到了哪一步；**`40703`≠`40705`**（签名 vs 会话），别混判。
- ★ **无票 `POST` 对任何已注册路由都被鉴权中间件拦在 handler 之前**（实测 `open/claim/verify-segment/handshake` 无票一律 `401`）⇒ 因此**无票 POST 全量枚举是零写入的**，可安全用于路由测绘；一旦脚本要**带票**打 `open/claim` 就等于资金面，必须单独授权。
