## ★★★ 铸票 fragment 解析 + token「不可伪造」变异矩阵（2026-09 增补，独立复跑实证）

- ★★★ **`RequestAppWebView` 返回的 URL fragment 不是 initData 本身**：形态为
  `#tgWebAppData=<URL编码>&tgWebAppVersion=7.0&tgWebAppPlatform=android&tgWebAppThemeParams=…`
  ⇒ 必须 `parse_qs(fragment)["tgWebAppData"][0]` 取出（已解码）才是可注入的 initData。
  **把整段 fragment 当 initData 送 ⇒ 受保护端点一律 `401/40701`**，表象像「凭据无效/已过期」，实为**我方缺陷**，极易白烧一轮。自检：对 initData 再 `parse_qs` 应看到 `auth_date/user/hash/start_param` 等 ≥5 键（缺则注入错）。
- ★★★ **证明 token「不可伪造」的标准程序 = 字节变异矩阵**（比只报结论硬得多，且全程只读）：
  1. 对照：真 token `GET /rp/detail?token=<裸载荷>` ⇒ `200` 并解出 `packet_id`；
  2. 解出 token 原始字节并**与响应字段对账**（实测 18B = `6×00 ‖ uint16 BE packet_id ‖ 10B 随机`，`0x1D6D == 7533` ⇒ 结构判定有据）；
  3. 变异组：**改包号首字节 +1/+2/+3**、**翻转尾部 1–2 字节**、**反转包号段**、**拼 id∈{0,1,2,100,真实 id,真实 id±1} + 零尾**、**小端包号 + 真尾**；
  4. **任一变异回 200 或换出别的 packet_id ⇒ 可伪造/可枚举（IDOR，立即深挖）；全部回落同一 `40671` ⇒ 服务端按整串查库 ⇒ 非 IDOR**（实测 T1–T8 全 `40671`，负控通过）；
  5. **用同一 token 打媒体/资源类端点做交叉对照**：真 ⇒ `200`（实测 115,618B JPEG），改过 ⇒ `404/0` ⇒ 该代理同样校验、不解析外部 URL ⇒ 无 SSRF 面。
- ★★ **诱饵页可能有多份变体**：实测 admin 类路径 = 6249B「<产品名>运营管理控制台」假登录页、敏感文件类 = 5882B、惩罚页 `/gotcha.html` = 9309B ⇒ **尺寸阶梯本身就是多值 oracle**（SPA 兜底 / 诱饵 A / 诱饵 B / nginx 404 513B / Go 404 18B）。**判真假只看表单 submit 处理器与链接真伪**（`window.location.href='/gotcha.html'`、`href="#"`），**不看标题像不像后台**。★ **同一路径的尺寸还会随时间/请求变化**：实测 `/admin` 出现 **2276B ↔ 6249B** 两值、404 有 **CF 167B / nginx 513B / Go 18B** 三态 ⇒ **尺寸永远只作辅助信号，判据必须是 title/内容/处理器**。
- ★ **同源两 vhost 共用一套诱饵** ⇒ 判「同一 nginx + 同一 origin」：admin 类路径两边回**同尺寸诱饵**，而业务路径一边回 SPA、一边回 Go `404/18`（后者 = 纯 API/蜜罐 vhost）。
- ★ **尺寸差分必带同窗负控**：站点的 index 体积会因 CF beacon / UA / Accept 变化（如 728B vs 1095B 同站同页）⇒ 不设同批次随机路径负控，就会把 SPA 自身当「命中」。
- ★★ **`405` 必做「随机路径负控」（本轮血泪）**：某站 nginx **只把 `/api/miniapp/v1/` 前缀代理到 Go 应用**，其余路径走静态 location ⇒ **任意 POST 一律 `405/550B` nginx 默认页**。实测 `POST /callback` 与 `POST /<随机不存在名>` **逐字节一致** ⇒ 当轮扫出的 **14 条「回调路由」命中全为假阳性**，必须整条删掉而非写进报告。
  **正控配方（三条一起打才算证据）**：① `POST <真实 API 路由>` 不带凭据 ⇒ 应回**应用层 401**（证明 POST 能穿透 nginx）；② `POST /api/<伪路由>` ⇒ 应回**后端 404（体积小、非静态页）**（证明 API 前缀确被代理）；③ `POST <随机非 API 路径>` ⇒ 与待测路径响应**逐字节比对**，一致即 **零判别力**。
  副产物：`mch` 类 vhost 把**全路径**代理到 Go ⇒ 这才是「全路径 404/18B」的根因（不是「无站点」）。
- ★★ **`CF-Connecting-IP` 探针禁忌**：对 CF 前置站发该头 ⇒ CF **error 1000**（`403`；正文在 **17B 裸文本 `error code: 1000`** 与 **8101B 完整 CF 错误页（含随机 Ray ID）** 之间切换）⇒ **必得假 403**，绝不可读作「路径被拦／需鉴权」。
- ★★ **判「纯 API vhost／无后台」不可由 API 前缀外推**：实测某 vhost `/api/*` 前缀全 `404/18B`，据此写成「全路径 404、无内容」；补测**裸后台路径**才发现 `/admin`·`/admin/`·`/dashboard` 返回 **200 + 与兄弟 vhost 逐字节相同的诱饵页（同 md5）**，而 `/<随机名>`、`/dashboard/` 回 `404/18B`（**负控通过**）⇒ 必须覆盖「裸常见后台路径（有/无尾斜杠各一发）+ 随机路径负控」，只测 API 前缀＝无效证据。
