## ★★ 诱饵基线 · 同族开源审计 · 成品结果回收（2026-09 实战增补）

- ★★ **判断「某个 API 命名空间是否存在」必须用诱饵基线**：先取**随机路径** + **已知业务 404 路径**两个基线，再逐路径比 `md5(body)`。实测某站：`/user-api/*`、`/agent-api/*`、`/admin` 全回 **200 且 md5 = 随机路径同值**（= 站点 catch-all 诱饵页）⇒ 判「不存在」；`/api/...` 回 **Go 原生 `404 page not found`**(18B) ⇒ 判「未注册」。**只看状态码会把诱饵当命中、把负结论写成正结论。**
- ★★ **「同族开源」≠「目标同实例」**：可从**运营方自己的销售频道**（商铺/招商/技术群）反查家族开源源码。实测命中 `github.com/TGlimmer/TG_walletbot`（Go 红包钱包 + `/api/v1` 后台 + `migrations/000022_seed_admin_users.up.sql` 种子超管 bcrypt + nginx 拓扑 `/`→管理前端、`/api/`→后端 ⇒ **管理端是独立主机**）。审计完**必须回目标实测**：用诱饵基线证明目标**不挂**该后台（`/api/v1` 404、`/user-api` 诱饵）⇒ 默认口令只作**家族情报**，不得写进目标的漏洞报告。
- ★ **种子哈希离线破解是零成本情报**：对 `migrations/*seed*admin*.sql` 的 bcrypt 哈希跑 30 个常见候选（`bcrypt.checkpw`，实测命中 `admin123`）⇒ **先离线，绝不先对目标做在线登录尝试**。
- ★ **公开源码里找不到目标私有实现时，用「特性指纹」证伪而非猜**：拿只有目标才有的字段名（`verify-segment`/`grid_size`/`automation_suspected`/`client_ipv4`）去 grep 归档的上游仓库；**全 0 命中 ⇒ 公开源不是目标实现**，收线换面，别在开源里硬找洞。
- ★★ **`DataInvalidError` 第四成因 = 服务端 callback 白名单**：同一页上下文内 `gbh_list:1:all` 成功、`gbh_list:1:<任意 id>` 立刻 `DataInvalidError` ⇒ 回调参数**由服务端校验**（第三参=时间筛选、第二参=页码，**无用户维度 ⇒ 无 IDOR**）。⇒ 穷举 callback 参数打 IDOR 是死路；测 callback 只能发**键盘上真实存在的 data**，且**必须先导航到该页再发**。
- ★ **远端长跑扫描的产物要回收，别重跑**：把结果 `tee /tmp/xxx.out`；SSH 抖动（`Error reading SSH protocol banner`）**重试 1–2 次**即可回收成品（实测回收 `SVCS=92 ROUTES=77 methods=PUT,DELETE jobs=14168 → hits=0`）。跑扫描前先看产物在不在，避免重复烧几万探针。
- ★ **枚举 oracle 要有「已鉴权正控」**：同一基址下 `/api/miniapp/v1/rp/detail` 匿名回 **401**（真端点）就是最好的正控；正控为 0 时任何「全 0 命中」只能记**不可判定**。
