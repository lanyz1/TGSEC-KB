# PixBot v7/v8 会话实录:手机自适应 + 数据质量 + 部署陷阱

## 手机自适应列表(文本+数字直达)
- TG 手机上一行两按钮只够 ~6-8 中文字 → 长名列表必须"文本行 + 数字按钮"。
- 每页 5 条:文本行(序号+🔥/📚+全名+次行信息)+ `[1..5]` 数字按钮(`listopen:{page}:{idx}`)+ `[⬅️][n/N][➡️]` + `[🔙]`。
- handle_text 数字回复优先(先于 PENDING_INPUT),用 `LIST_STATE[cid].page` 换算。
- **分页索引偏移 bug**:idx 是页内序号,打开必须 `real = page*per + idx`;callback 必须带 page。症状:第2页点5打开全局第5(用户实测发现)。修复后模拟验证 page=1,idx=4 → real=9。
- 按钮宽度:全角空格填充被 TG 裁剪(无效!);真实文本才撑宽;但手机两列 >10 字截断 → 显示全优先,文本 ≤6 字。

## 公告推送纪律(用户两次纠正"怎么又没推送更新公告")
- 部署五步:改码→编译→上传→重启→**推公告**。漏推=用户纠。
- 去重:`last_push.json` {v,t};同版本 30min 去重(部署脚本重复执行只推一次,`推送: []` 即命中去重);manual=True 强推。

## 删除功能误删回调(用户:"加速器点击没反应")
- 正则删功能会误删相邻 `elif data ==` 分支(accel/settings 实测被删)。
- 对账脚本:提取 callback_data 字面量 vs 分支(注意 `elif data in (...)` 元组与 `if data ==` 非 elif 会被简单脚本漏报);残留死函数无害。

## 企业名归一化 + 统计口径(用户高频反馈"公司名称不显示/统计不匹配")
- dwhz=企业自填(简称/"?") vs 供应商官方库(全称);"?"=接口漏名,同账号不同时刻返回不同。
- 归一化链:核心名→全称(merger/bot);账号→全称(resolve_acct_name 全库 pack_map 聚合,缓存5min);兜底账号。
- **CSV 生成器必须过归一化**(报名明细/18列/查询工坊三处),否则 CSV 出现"?"——用户拉 CSV 发现"公司名称不显示"根因。
- 统计口径:已报名且未结束=进行中(status 14/22 排除,status 缺省用 bidStarttime 兜底);显示"已报名 N(进行中 X | 已结束 Y)"。
- 档案滞后:企业档案是快照,pool_clean 后新报名不计入 → fmt_enterprise 动态合并 live pack_map 记录(归一化名/账号匹配,projId 去重)。

## merger 覆盖全量文件(数据灾难)
- write_all_summary 用 29 个 live 项目覆盖"全量_企业包件_18列.csv"(221,661行→42行)——实时汇总必须写独立文件(实时项目汇总_18列.csv),全量改名"全量_历史_..."且 bot 下载入口指向全量。
- **部署路径陷阱(最重要)**:daemon 实际运行 `/opt/v6/merger.py`,但历次上传到 `/opt/v6/t95306_v6_merger.py` → 修复从未生效,旧版继续覆盖!**任何部署前先确认 daemon 实际运行的文件路径**(cat merge_daemon.sh / ps aux 看真实命令),上传到正确路径后再杀进程重启;pkill 只杀脚本名不杀 python 子进程 → 用 `pkill -9 -f '[t]95306_v6_merger.py'` 精确杀。

## 数据源限制(回答"为什么企业数据不全")
- ST TTL 30min:只有"当天活跃报名企业"能拉到包件明细;报名截止早的项目实时接口拉不到 → 靠官方快照文件补。
- 8515 快照(8/28):项目级(企业名/信用代码/时间),**无包件明细**;部分项目只有公告行(无企业)→ 剩余 0 企业项目是数据事实,持续监控等新报名。
- 08文件:包件级全量(615K)但**只含已结束项目**。
- 补采:collect_one --pid(指定项目拉公告包件)+ /repackall 批量;实时补采靠多 ST 轮询(审计最新 N 个不同企业 ST,多轮累积)。

## 其他
- 缓存预热:首次遍历 13K 文件/369K 供应商名会卡 2-5s → 启动后台线程 _warm_caches 预热。
- 防火墙加固后本机直连采集机被禁(只放主服 IP)——所有采集机操作走主服跳板;SSH 加固顺序:密钥先行测试→禁密码→防火墙→recent 限速,防锁死。
