# 中国法院文书解读与复议/应诉文书起草

处理用户真实的法院事务(非渗透目标):阅读法院电子送达的文书,判断性质与期限,给出策略,起草复议申请书/答辩文书。用户偏好:简体中文、表格化要点、明确行动清单、最终交付 .docx 到桌面。

## 一、读取法院电子送达文书

- 典型入口:人民法院执行信息公开网 `zxfw.court.gov.cn`,路径 `#/pagesAjkj/app/wssd/index?qdbh=...&sdbh=...&sdsin=...`(网上送达 SPA,H5 移动端样式)。
- 用 open_preview 打开 + read_preview 读文本;SPA 渲染后正文通常只列出 PDF 文件名(如 `5114202609070032.pdf`),无交互元素。
- **文书正文本体需用户从页面/短信下载**(PDF 或转存 docx 到 Downloads)——不要在本机 curl 抓 PDF 下载接口(国内法院站有反爬+需鉴权 token,且用户已有文件时是浪费)。用户给 docx 后直接 read_file 提取全文。
- read_file 对 .docx 自动提取;多文件可能是同一文书分页(正文页+盖章落款页),要合并理解。
- 判断真伪:域名必须官方(court.gov.cn 系);法院送达不会要求转个人账户(见下)。

## 二、罚款决定书(民诉法)快速判断

- 法条框架:
  - **114条**:伪造/毁灭重要证据、妨碍法院审理等 → 可罚款、拘留;构成犯罪追刑责。
  - **118条**:个人罚款 ≤10 万元。
  - **119条**:被罚款人不服 → 可向**上一级法院申请复议一次**(复议期间不停止执行)。
- 决定书常见写法:**只写明查明事实 + 引用法条,不写"故意伪造"等定性说理**——这是复议抓手(认定事实与适用法条间缺说理),不是"没认定"。
- 期限算术(铁律):电子送达以到达系统当日为收到日;**收到次日起算 3 日**复议窗口;交款期限以文书为准;两者常重合,务必先保程序。跨省邮寄 EMS 留 2-3 天,所以**当天/次日必须寄出**,别掐点。

## 三、核心策略:交 + 同步复议(占优策略)

| 结果 | 处境 |
|---|---|
| 交+复议成功 | 罚款退回,损失仅邮费,且获得"无伪造故意"认定 |
| 交+复议驳回 | 与直接认罚相同,多花邮费 |
| 不交+复议 | 复议不停止执行 → 逾期被跨省委托执行/冻卡/执行记录 |
| 不交+不复议 | 最差,被动 |

先交钱消除执行风险,复议保留翻盘可能。**复议申请书先寄出保程序,证据后补。**

## 四、复议申请书论证结构(针对"提交虚假材料被罚"类)

请求两项:①撤销罚款决定;②如认为应予处罚,依法减轻/免除。
- **论点 A(证据不足)**:决定书只查明材料虚假(非某律师申请、非某派出所出具),未查明制作人、交付渠道、被罚款人是否明知/参与 → 114 条"伪造故意"构成要件缺证据。
- **论点 B(细节反证)**:假材料上精确印着真实律所名/律师名/派出所名/专用章样式——普通当事人不可能知晓,恰证材料系第三方制作交付,当事人只是被动接收者。
- **论点 C(姿态)**:承认"审查不严的过失",不硬顶"我没责任";请求考虑无伪造故意、受误导、认错诚恳 → 减/免。
- 措辞红线:不要写成"文书没写所以我没责任",要写"无证据证明故意 + 细节证明非制作人"。

## 五、缴款路径与防骗红线

- 决定书正文**一般不写账户** → 需主动致电法院:值班电话 / 法院热线 12368,报案号+当事人姓名,问**对公账户**或**非税缴款码/电子缴款通知书**。
- 河南走财政非税:支付宝搜"豫事办/河南非税"小程序 → 非税缴款 → 输缴款码,缴完拿电子票据。
- 无缴款码时:问清账户后银行柜台转账,附言案号+姓名,留回单。
- 🔴 **红线:罚款绝不转任何个人账户/私人码**,只缴法院对公或财政非税专户。黑产常在当事人收处罚后冒充代缴诈骗。
- 凭证留存:银行回单/电子票据截图(复议撤销后退款需要)。

## 六、寄送与交付

- 双寄保险:EMS 特快专递寄**上一级法院(复议机关)** + 副本交**原决定法院转交**;信封醒目写"复议申请(案号) 当事人姓名";保留面单查签收。
- 交付物:用 docx skill 生成 Word(styles 参数必须是数组 `[{"name":..,"base":..,"font":"SimSun","size_pt":12,...}]`,边距用嵌套 `margins_mm`;spec 内中文引号要用全角否则 JSON 校验失败);存 Downloads 并**复制一份到桌面**;预留空位(电话、签名、日期)提示用户手填。
- 检查要点:电话栏、落款日期留空占位;提醒"打印→签名→EMS→电话要缴款码"四步。
