# 锁粒度判定与喷洒预算（实证：opensms V-IM 短信平台 2026-09）

喷之前必须回答两件事，答错就是白烧几小时：
1. **锁按什么分桶** —— 账号级还是 IP 级？（决定出口池有没有用）
2. **每个目标的可用预算有多大** —— 变体数 × 窗口阈值。（决定 ETA 和优先级）

---

## 1. 锁粒度：40 个出口的判决

**做法**：拿同一个账号，从 40 个**互不相同**的出口各发若干发失败登录（出口=免费代理池 + 付费代理混合）。

**实测结果**：不管换哪个出口，全部回同一句
`账号已被锁定，请2分钟后再试` ⇒ **锁是账号级、与 IP 完全无关**。

**推论（战术级）**：
- 免费代理池 / Tor 的价值只剩**穿 WAF**（拿真响应），**对绕锁零收益**——别再为了「绕锁」去堆出口。
- 喷速上限 = `阈值 / 窗口`，与出口数无关。实测该站 `15 发 / 2 min` ⇒ **≈450 发/小时/账号**。
- 后续所有 ETA 必须按这个天花板算，别再写「多出口池提速」这种未取证的乐观结论。

通用脚本：`scripts/lock_granularity_probe.py`（相 A 测阈值、相 B 换全新出口复测判粒度）。

## 2. 变体预算：`2^L − 1`，中文名是 0

该站锁按**原始用户名串**分桶，且 `ci`（大小写不敏感匹配 + 无 padding），于是**大小写变体各自独立成桶**：

| 账号名 | 变体数上限 | 每窗口预算 | 时喷速上限 |
|---|---|---|---|
| 拉丁名，L 个「有大小写之别」的字符 | `2^L − 1` | `15 × (2^L−1)` | 示例 `daili1`(L=6) → 63 桶 → 945/2min |
| 纯中文 / 纯数字 / 纯小写无关名 | **1** | 15 | 450 发/h |

⇒ **先给每个目标算一遍可达喷速**，把预算花在拉丁名/短名前缀上；中文名按 `450/h` 老老实实排 ETA（全量 2150 词 ≈ 4.8 小时/账号）。

## 3. ★ 陷阱：锁死型账号会在长表战役里饿死

**现象**：跑「N 账号 × 2150 词」的扁平对表时，拉丁名账号几小时里吃掉上千发，而中文名账号只推进了 **12–14 发**。

**原因**：`while true` 循环只在**整张对表打完**后才 `sleep` 重置预算；一个 tranche 的时长由最快的账号支配（数小时）⇒ 被锁的账号每轮只吃到头 15 发就全程干等。

**修法**：锁死型账号**单独开进程**，用**短优先表 + 窗口循环**：
```bash
while true; do
  python3 brute.py LOGINS_CN.txt wl_top300.txt >> cn.log 2>&1
  sleep 125            # 略小于窗口，等锁过期
 done
```
每轮 = 每账号 15 发；`2150` 词全量 ≈ 6.4 小时，前 300 词 ≈ 55 分钟。与广表战役**并行**跑，互不干扰。

## 4. 目标优先级：用目录里的业务计数字段排序

BOLA 拿到的全量名录（见 `references/relationship-endpoint-field-leak.md`）里常有业务量字段。本案 `dayliModelTimes` = 该账号手上的实体数量（卡数）：

- 493 个账号里**只有 9 个 > 0**：`小宇中控` 11281、`syt` 5204、`fly` 4902、`daili1` 561、`qing01` 246、`qing03` 200、`中文测试` 153、`测试中控2` 50、`测试中控` 4。
- 客户号（34 个已破，全是 `123456`）**灌库全空**（`chats=0`）——平台批量建的僵尸号，无卡无短信。

**结论**：数据面只存在于这 9 个账号的 IM chat 面上 ⇒ **别平铺喷 493 个**，弹药压在计数最高的少数账号上；广度只用来确认「哪一类账号是空壳」。

## 5. 顺带的两条写原语纪律

- **写原语的越权判定必须用「重登 + 取新 token 再读」验证**，别看单次响应文案。实测 `PUT /users/updatePwd` 带别人的 `userId` 回「成功」，实际该参数**被忽略、只改自己**（负结论，已落档）——且此动作会**把自己的口令轮换掉**，后续拿旧口令登录失败，别误判成「账号被封/被改」。
- **改密接口常自带频率限制**（实测 429）⇒ 探针要退避重试，不要在同一轮里连打。

## 6. 登录响应的第三种文案 = 存在性预言机

失败文案族一次抓全（对比登录不同账号即可）：
- 口令错 → `用户名或密码错误`
- 被锁 → `账号已被锁定，请2分钟后再试`
- **删除态 → 独立的删除文案**（对已删除账号即使口令正确也回它）

⇒ 第三种文案让「账号是否已被删除」变成免口令判定，也是**判断某名字曾被注册过**的免费 oracle。脚本分类把它们分开记，别全归成 FAIL。
