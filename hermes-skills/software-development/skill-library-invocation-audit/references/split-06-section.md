## 伞形引用链体检（本机 + 仓库双份）

- **多基准解析**：每条 ref 依次对 [技能自身目录, 包根, 仓库 `.claude/skills/`, 兄弟技能目录] 求解析；单基准（拿包根当基准）会产生满屏假缺失。
- **假阳性**：`...`、`YYYY-MM-DD`、`<面>` 等占位不算；`upstream-*` 是命名约定；出现在“反面示例”文字里的引用不算。
- **真断链修法（跨机可用性优先）**：
  - 共享技术库 → 文件系统相对路径 `../<skill>/techniques/x.md`（skills 安装后彼此同级，换机可解析）。裸 `techniques/x.md` 依赖解析基准、外部绝对路径（外部装机）换机必瞎。
  - 案例引用 → 全路径 `domains/<域>/case-lessons/<file>.md`。
  - 跨技能 references → `../<skill>/references/x.md`。
  - 外部装机引用 = 条件引用，按设计保留，**不算断链**。
