# 拆完怎么验：静态闸 + 真调用冒烟

拆段/压平的验收顺序：`compile()` → 结构闸（目标条消失 + 无新增超限 + 宿主文件 ≤上限）→ 未绑定名审计 → **真调用冒烟** → 全量门禁。
前三级**全绿也不代表没坏**（本类任务已多次实证），真调用是唯一能抓到下面那批破坏的闸。

## 冒烟夹具的形状（可复用）
- **补丁打在模块级名字上**：宿主函数体里的调用是运行时查模块全局 ⇒ `import mod` 之后 `mod.get_json = fake`、`mod.write_json = fake`、`mod.sleep = fake` 就能拦下真网络/真落盘；helper 之间同理（要测的 helper 也改名替换）。不改源文件、不打桩类。
- **场景矩阵**：每条被抽出的 helper 至少一个正常路径 + 一个边界；常见边界集 =
  空输入 / 全字段缺失 / 反查未命中 / 「前置守卫失败 ⇒ 提前返回且零副作用」/ 连续失败达阈值停手 / 提前返回哨兵（调用方据此收尾）/ 返回值贯通（`__ret__` 旁路）。
- **每个用例独立复位全局夹具**：跨用例共享的计数器/缓存/日志列表会被上一个用例污染，症状是「莫名多一次调用」——比坏代码更难查。
- **断言器**：`ck(name, cond, extra="")` 逐条打 `✓/✗`，末尾 `sys.exit(1 if bad else 0)`；日志重定向到 scratch（`TMPDIR=<scratch> python3 … > log`），事后 `grep` 得到「N/N 全绿」。
- **桩不继承真类**：需 `self` 的 helper 用**未绑定方法调用**（`Cls.method(fake_self)`）或 lambda 手动接线；只读属性的用 `types.SimpleNamespace` 造假 self。夹具字段名必须与真代码一致（读 `it["pid"]` 就别只给 `projId`）。
- **列表参数位置要包一层**：真代码若传的是「无参可调用」，夹具别直接把 list 塞进去（`lambda **kw: tk`）。
- 需要真文件路径的 helper，用**不存在**的路径跑「跳过」分支也是有效用例；不要伪造生产数据。

## 证明「搬对了位置」的 AST 断言
- 外移函数必须是**模块体的直接子节点**（类内方法则是**类体的直接子节点**），且 `col_offset` 与目标一致 —— 防「helper 被插成目标函数内部的嵌套函数」（`compile`/棘轮/绑定审计全绿，只有真调用 `AttributeError`）。
- 宿主函数拆完应当只**剩下有意保留的嵌套 def**（例如只有一个内层闭包）：遍历时排除函数自身，否则断言恒真。
- 计数/存在性一律 AST，不用 `str.count`（子串与 docstring 都会污染）。
- 反向 import 成环的解：零件侧写**同名惰性包装**（函数体逐行原样、运行时才反向取用），别改调用点。

## 新旧差分（最强判据）
有原版就同一用例矩阵分别喂旧/新两份模块，逐字节比结果（例：某 helper 17/17 完全一致才算过）。无原版时用「每 helper 一条真分支」补覆盖——只测过 happy path 的冒烟等于没测。

## 静态检查会漏掉的破坏（漏检清单）
- 闭包外移时把 `def` 行一起搬走 ⇒ helper 只是「定义嵌套函数 + 隐式 return None」⇒ 静默空转。
- 切走的块里绑定的局部名，宿主函数后面还在用 ⇒ `NameError`（要随参数注入**或**随返回值带出，两种都要）。
- helper 把失败返回改成 `None` 而调用方先解包后判空 ⇒ `TypeError`。
- 替换与插入顺序反了 ⇒ helper 自调用、原块留在原函数（行多重集对账照样绿）。
- 段边界把累加器初始化行切在段外 ⇒ `UnboundLocalError`（空池/空夹具时循环不跑，静态全绿）。
- 冒烟夹具本身错（路径前缀、字段名、参数个数、哨兵断言方向）⇒ 报出一批「失败」而真因在夹具；先查**共同**的匹配/前置条件。
