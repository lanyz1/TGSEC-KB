# 外部情报落盘：增量、权威性、证据纪律

把一份外部材料（清单 / 通告 / 扫描结果 / writeup）变成仓库或库表里的资产时照本卡做。
不重复任何仓库的目录地图或落盘清单（那些在仓库自己的技能卡里）。
触发：落库、补录、第二批、把这份清单进仓库、完善学习、字段来源、补丁差分、探针自测。

## 1. 增量补录（同一天/同一批次第二次进料）

**绝不重写既有文件。** 重写会丢历史、改坏聚合计数、把已入库条目的字段覆盖掉。

1. **先去重**：用主键（`cve_id` / `id` / 单号）对比既有条目，分成「已在库」与「新增」；
   已在库的不重写，交付里明写「本批 N 条为新增，其余已在首发」。
2. **只 append**：条目追加到数组尾；聚合计数（`stats` 之类）**只在原值上 `+=`**，不重算、不覆盖。
3. **正文新增章节，不重排全文**：加一节（如「当日二批补录」），保留原有章节顺序与编号。
4. 用 `scripts/append_daily_entries.py`：默认 dry-run 打印计划（新增/跳过/stats 增量/将插的章节），确认后 `--apply`。

## 2. 成批改文件：脚本 + 锚点断言（不许一长串内联命令）

- 把多处文本改动写成一个短脚本：**每处替换前断言锚点存在且唯一**，未命中就报错退出。
  否则会「静默漏改」或「同文件多处编辑互相覆盖」——两者都不报错，只会交出一份缺了几处的文件。
- 脚本写到 `tmp/` 再跑，别把多行 `python -c` 塞进终端。
- 改同一个文件的多个锚点，放进**一个**脚本原子完成；分多次调用同一文件有覆盖风险。
- **写完必回读校验**：条数 + 关键串（章节名 / 新增计数 / 真根因关键词）。没过不算完成。

## 3. 权威字段：只写源里真实存在的

铁律：**拿不到就写「未取到」，禁止补 0、禁止猜 CVSS、禁止臆造 CWE、禁止抄二手转述。**
端点清单与差分读法见 `references/权威字段源与补丁差分.md`。

- 字段源优先级：官方 CVE 数据库 API（比详情页早且带原始字段）> 厂商安全通告 > 发行方 bugzilla > 二手。
- 概率/评分类（EPSS 等）**新条目常无分**，命中率 3–5/10 是常态 —— 留空并备注，不填 0。
- 「厂商口径 vs 数据库口径」不一致的分数/向量：**两个都留**，别只留一个。

## 4. 真根因来自补丁差分，不来自通告文案

在野洞/待定级洞**必做**：抠出公开修复 `PR #` / `commit <sha>` / 版本更新级别 → 拉 `.diff`/`.patch` → **只看三处**：

1. **catch 分支是否吞异常**：`catch (X) { log; return; }` 后请求继续走 = **fail-open 放行**
   （真根因多是这个，通告文案只写「校验不当」）。
2. 校验失败后是 `return`（放行）还是 `throw`（拒绝）。
3. **官方回归测试的断言**：断言里的期望状态码/期望拒绝行为，直接当作自己写的探针的判定基准 —— 别自创 oracle。

副产品：把模式记成**类级试法**（同类拦截器/校验器结构可横向试），而不是只记住某个编号。
只有 bugzilla 且 `status=NEW` = **无公开补丁** → 不编 PoC，走类级变体表，交付写明「无补丁」。

## 5. 探针/工具：本地假目标自测过才算可用

写 `tools/ops/*_probe.py` 这类会被下一个会话直接执行的脚本时强制：

- **dry-run 默认**：不带参数只打印将要发送的请求，不发包；真发包必须显式 `--authorized`（授权闸门）。
- 默认**只读**（GET / 状态码差分）；会建对象或写状态的步骤（注册、建 remote、写配置）另开关，
  并在输出里写明「测后清理」。
- `--json-out` 落证据（URL / 载荷形态 / 状态码 / 片段）。
- **写完用本地假目标自测三条**（照 `templates/probe_selftest.py` 起 127.0.0.1 假服务）：
  ① dry-run 一个包都没发 ② 命中判定正确 ③ 无授权标志时拒绝发包。
  **自测没跑过，不许说探针可用**；假目标还能顺带验「已修复 / 未修复」两种行为。
- 本机常带全局代理：自测时清掉 `HTTP(S)_PROXY` 并设 `NO_PROXY=127.0.0.1`，否则请求被代理截走会假失败。

## 6. 诚实边界（交付必带）

- **不许把「未运行」写成「已验证」**：跑不通的工具（缺二进制、平台不符）只做结构校验（YAML/JSON 解析），
  并在交付里单列「诚实边界：未执行」。
- 交付回报给「产物路径 + 一条可复现命令」，不只丢一份清单。
- 合并类交付要报**数字对账**：新增多少 / 跳过多少 / 总数多少 —— 三者都能从脚本输出直接读到。

## 支持文件

- `scripts/append_daily_entries.py` — 增量补录（去重 / append / 计数 `+=` / 锚点插章节 / 回读校验），默认 dry-run。
- `templates/probe_selftest.py` — 本地假目标自测模板，改两处 TODO 即可验探针三条行为。
- `references/权威字段源与补丁差分.md` — 字段源端点、bugzilla 状态语义、差分读法、证据分级。
